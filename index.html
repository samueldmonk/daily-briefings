How these pages are built
Each briefing is rebuilt from scratch every thirty minutes from live web searches. Nothing is carried from memory: every claim, number, date, score and name on all four pages has to trace to a source fetched in that run or to a standing, sourced correction. Where two sources disagree, both figures are printed rather than averaged. Where a claim could not be confirmed, the page says so by name instead of quietly dropping it. Point-in-time snapshots of every edition are kept in the Archive.
