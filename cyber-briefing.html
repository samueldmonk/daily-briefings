Top Story

PHP2Shell: emergency PHP patches for two pre-auth RCE flaws, with attacks already logged

The PHP team released 8.5.12, 8.4.27, 8.3.36 and 8.2.35 to fix CVE-2026-109618 (RCE via out-of-memory corruption) and CVE-2026-109619 (RCE via stale global state). Every PHP installation serving web requests is affected — PHP-FPM, Apache mod_php (greatest danger), php-cgi, FrankenPHP and LiteSpeed — and a working exploit shows a single unauthenticated request can trigger the attack before any application code runs (Help Net Security).

Details leaked on Oct. 20, a day ahead of the embargo; Cloudflare logged the first attacks at 07:43 UTC on Oct. 21, hours before the ~14:00 UTC patch window, and has pushed WAF rules to all customers — which its CTO calls “a STOPGAP only.” Reuters reported cybersecurity-agency websites in the Netherlands and Finland went dark as a precaution (Investing.com via Yahoo).

PHP 8.1 and earlier get no official fix; the team published minimal source backports for 7.4, 8.0 and 8.1. The UK NCSC urges taking offline any system that can’t be fixed right away. “It’s one of the biggest vulns in years,” said Kevin Beaumont (Help Net Security). PHP says there is no complete mitigation short of updating (php-src releases).

Patch Priority

Patch now: PHP — CVE-2026-109618 / CVE-2026-109619 (CVSS v4.0 9.2). Upgrade to 8.5.12, 8.4.27, 8.3.36 or 8.2.35; check your distro/LTS vendor for packages; consider taking unpatchable systems offline (Help Net Security). Not yet in CISA’s KEV, so no federal deadline applies.

Federal deadline: Plex Media Server CVE-2026-96656 and CVE-2026-96654 (the Plex2Shell chain) plus SiteGuard Server Edition CVE-2026-106931 — due Friday, Oct. 23, 2026 (2 days left). Fixed in Plex Media Server 1.43.3.10861 (THN).

Threat Actor Spotlight

Ransomware

Qilin — riding a Palo Alto VPN bypass into networks

Unit 42 updated its threat brief on Oct. 19 naming Qilin and Inc among operators exploiting CVE-2026-0257, a PAN-OS GlobalProtect authentication bypass patched in May; ReliaQuest also tracks Qilin and Settra. In one case attackers went from the VPN gateway to vCenter, disabled ESXi security controls and pulled credentials offline from a domain controller’s virtual disk. ReliaQuest: “Patching alone may not remove access established before remediation” — end active GlobalProtect sessions after patching (Help Net Security).

Breaches & Incidents

NewSupply chain

ConnectWise pulls Cloud Backup after Microsoft 365 abuse

A compromised ConnectWise Cloud Backup credential was used to reach customers’ Microsoft 365 tenants; Microsoft says attackers likely abused permissions such as Directory.ReadWrite.All. Huntress saw unauthorized sign-ins in 162 tenants after attacks began around Oct. 15. Cloud Backup, SaaS Security and Cloud Management are suspended with no restoration timeline; ConnectWise says there is “no indication” backup data was compromised (The Record, Oct. 19).

Supply chain

OVHcloud CLI releases swapped for an info-stealer

A hacker used a developer’s GitHub account to replace binaries on five releases (v0.11.0–v0.15.0) on Oct. 19; CEO Octave Klaba urges affected users to change every secret on the machine. OpenSourceMalware ties it to GlassWorm (Help Net Security).

Supply chain

AOMEI Backupper update servers hijacked (UNC7017)

Google/Mandiant attribute minutes-long tampering windows (May 28, July 16, July 20) to UNC7017, delivering the CROSSROAD downloader and SHINYROAD backdoor; infected machines stay compromised after AOMEI’s server fix (BleepingComputer) (CSA).

Ransomware

GlobalProtect intrusions across sectors since June

Healthcare, education, government and energy victims; attackers chained Veeam CVE-2023-27532 in some cases (Help Net Security).

Exploitation

Plex2Shell used to drop miners and proxy malware

Researcher boredhackerblog found the chained Plex flaws weaponized to deploy cryptocurrency miners and proxy malware, prompting CISA’s KEV listing (THN).
