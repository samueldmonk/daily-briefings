Top Story

“MikroTrick”: attackers are taking MikroTik routers over the internet with no password at all, and the federal clock runs out today.

CERT Polska warned that attackers are actively exploiting two zero-day flaws in MikroTik RouterOS that can be combined to take full control of the device without authentication, provided it accepts remote access over SSH. The chain is codenamed MikroTrick, and it draws on a set of six identified flaws: CVE-2026-67276, CVE-2026-67277, CVE-2026-67278, CVE-2026-67279, CVE-2026-67281 and CVE-2026-86060.

The mechanics split cleanly. CVE-2026-67276 and CVE-2026-86060 (CVSS 9.2) allow an attacker to bypass authentication and elevate privileges. CVE-2026-67277 is the plumbing: combined with a disclosure of uninitialised data from the packet buffer and an integer underflow in size validation, it enables kernel memory leakage or a remote denial of service.

This is not theoretical and it is not new. CERT Polska states that successful attacks — including the creation of an “ops” account — have been occurring since at least 2 September, originating from 82.192.72.4, with 103.102.31.18 also used in attempts against the chain. That is eleven days of confirmed hands-on-device activity before today’s deadline — and eight of them before CISA set the clock running.

What to install: RouterOS 6.49.21 (Long-term), 7.23.4 (Long-term) and 7.24.2 (Stable). And because an “ops” account is the observed artefact, patching alone does not close this out — CISA’s own tiering agrees, having attached a forensic-triage requirement to CVE-2026-86060 rather than a patch-and-move-on instruction.

Patch Priority

Breaches & Incidents

Supply chainNew

Coder’s module registry was poisoned through its own Cloudflare infrastructure

Attackers gained access to Coder’s Cloudflare infrastructure and added unauthorised IP addresses to the pool serving Coder’s module registry. Those hosts served a version of the registry containing malicious Terraform modules that harvested environment variables, API keys, CI/CD credentials, configuration secrets, terminal history, OIDC tokens, SSH keys, external authentication tokens and Coder database passwords, exfiltrating to the lookalike domain coder-infra[.]com. Fixed in 2.37.0, 2.36.4, 2.35.7 and 2.34.9; Coder advises checking for connections to the malicious domains before patching.

Zero-dayOngoing

StyleSmuggler is backdooring Magento and Adobe Commerce stores

An unpatched Magento / Adobe Commerce zero-day gives unauthenticated attackers remote code execution. Sansec describes a two-stage abuse of Magento’s template system via styles properties: poison PHP code (for instance by generating a failure report), then let Magento execute it via a failed-payment email. The backdoor is a Rust program beaconing to 99.84.67[.]186, seen in two variants named fc-cache and chronyd; a separate cluster drops a PHP web shell into the product image cache. Attacks began 4 September 2026. The corresponding KEV entry, CVE-2026-75650 (Adobe CVSS 10.0), was due 11 September — already past.

MSP / RMMOngoing

N-able N-central: a fully patched customer was compromised anyway

N-able shipped hotfixes for two severe N-central flaws — CVE-2026-86206 and CVE-2026-86207, authentication bypasses giving full platform access — alongside CVE-2026-86218 (CVSS 10.0), pre-authenticated RCE on the N-central server. N-able says it has no confirmation of exploitation in production. Huntress disagrees in practice: it opened an investigation on 4 September after a customer’s fully patched N-central production environment was compromised, and believes one or both auth bypasses were likely leveraged — while conceding that limited appliance logging means it cannot definitively confirm which exploit was used.

IdentityNew

A new Microsoft 365 AiTM kit called Knight Office is running Docusign lures

Huntress documents an adversary-in-the-middle phishing toolkit that chains redirects — including one through the Monday work-management platform and a compromised Joomla site — to a phishing page that captures valid session tokens and feeds them to the Knight Office console. Stolen session tokens let an attacker use the account as if logged in, with no password and no MFA bypass required. At least nine identity attacks have been linked to the kit in the past two weeks. It joins EvilTokens and Kali365 in the same category.

AvailabilityNo CVE

September’s Windows Server updates are still breaking Remote Desktop

Microsoft’s September 2026 cumulative updates — KB5122876, KB5122882 and KB5122871, released 8 September — break Remote Desktop Services on Windows Server 2019, 2022 and 2025. Servers run normally for hours, then RDS connections fail and sessions cannot log off; some cases need a hard reset. Microsoft has told BleepingComputer it is investigating. Rolling back restores RDS but removes the month’s security fixes. Stated plainly: this is an availability defect, not a vulnerability — no CVE, no attacker.

Two things worth stating about how these dates are derived. First, do not compute them. CISA issued BOD 26-04, “Prioritizing Security Updates Based on Risk”, on 10 June 2026, superseding and revoking BOD 22-01 and its uniform three-week window. In its place is a 16-tier remediation matrix keyed to whether the asset is publicly exposed, whether the CVE is in KEV, and whether exploitation can be fully automated; the most dangerous tier must be remediated within three days, with mandatory forensic triage. Agencies must be operating to these timelines by 7 December 2026. That is why a same-week deadline is normal now, and why deadlines inside a single bulletin can differ — the 8 September batch of four split between 11 and 22 September. Second, KEV entry requires evidence of exploitation, so a severe flaw nobody has been seen exploiting carries no federal deadline at all. Absence from this list is not a severity judgement.

One unresolved item, printed rather than smoothed. The 12 September deadline set is given by The Hacker News as three flaws — Cisco, Citrix and Fortinet. A prior edition of this page also placed CVE-2026-87491 on that date, while a separate reading dates it 23 September. This page follows the 23 September reading and says so. Separately, GitLab’s add date is still unsupported: this page has carried it as an 11 September addition footnoted to an alert titled “CISA Adds One…”, but the 11 September alert is titled “CISA Adds Three…” and GitLab is not among the three. The CVE, the CVSS, the patched versions and the 14 September due date are separately corroborated and stand; only the add date and alert attribution do not.

Around the Wire

  • The perimeter problem is about vendors, not CVEs. A joint SentinelOne / Tenable analysis finds state-sponsored and criminal actors independently converging on the same edge infrastructure, and that the exposure picture is flatter than headlines suggest: Fortinet, the vendor most associated with edge attacks in the press, sits mid-pack at 25% container-grain exposure — well behind F5 at 54%, and inside a ten-point band with Check Point, Ivanti and Citrix.
  • SNMPv3, the secure answer, leaks before login. Research validated across roughly 470,000 internet-exposed endpoints shows standards-compliant pre-authentication responses let an unauthenticated remote actor identify a device’s vendor, confirm valid usernames and narrow its likely encryption settings — collapsing a multi-dimensional brute-force problem into focused password guessing. The upgrade CISA urges is still necessary; it is just not sufficient.
  • A QR code with no image. Kaspersky documents phishing that builds a scannable QR code out of text characters and markup in the email body. There is no attachment and no embedded picture, so image-based and OCR scanners have nothing to key off — and an inbox with images turned off still paints it.
  • Three files out of 1,973. A tampered Exodus wallet installer, disguised as an Apple “Background Service,” installs a genuine Exodus 24.33.4 wallet missing exactly one capability: any way for the user to interact with it. One altered file stops the window drawing; another turns a legitimate source file into a loader that maps a 10 MB in-memory RAT — hidden VNC and SOCKS proxy, browser credential theft, beaconing to Azure Table Storage rather than its own domain.
  • Indirect prompt injection reaches the summariser. Forcepoint shows an email summariser on an unguarded LLM pipeline can be hijacked by hidden instructions inside an email to produce false summaries with no signal of tampering to the recipient — hidden HTML styling that Outlook strips on paste, but not when a message is sent programmatically.
  • Enforcement, briefly. The U.S. and U.K. signed a memorandum of understanding to run parallel investigations and share targeting information against scam centres behind investment and romance fraud.
