Top Story

Patch Tuesday lands heavy: 394 fixes, three zero-days — and the WinSock driver flaw is already being exploited

Microsoft's August security release, published Tuesday, addresses 394 vulnerabilities across Windows, Office, SharePoint Server, Azure services, .NET, PowerShell and Visual Studio Code — including three zero-days (Cyber Security News; The Hacker News counts 398, BleepingComputer 400 and SecurityWeek 421, depending on what's included). The urgent one is CVE-2026-68820, a use-after-free in the Windows Ancillary Function Driver for WinSock (afd.sys) that Microsoft flags as exploited in the wild for privilege escalation; CISA added it to the KEV catalog the same day. Attribution has hardened: Check Point researchers report the flaw has been exploited by North Korean attackers — Lazarus — to deploy a kernel-mode rootkit in a new wave of Operation Dream Job (SecurityWeek, The Hacker News), with THN noting exploitation depends on winning a race condition in the driver and that Microsoft itself has not publicly attributed the activity. The other two zero-days were publicly disclosed but not marked exploited: CVE-2026-72971, a tampering flaw in the Windows Container Isolation driver (unionfs.sys), and CVE-2026-62832, an elevation-of-privilege bug in the Windows User Profile Service (Cyber Security News).

Beyond the zero-days, the release carries a Critical remote-code-execution flaw in the Azure Attestation and Device Health Attestation services (CVE-2026-71331), a Microsoft QUIC flaw (CVE-2026-62815) that an unauthenticated attacker can trigger with a crafted packet — one of four CVSS-9.8 bugs in the release that need no account, password or click, alongside flaws in Windows DNS Server, Windows Deployment Services and HPC Pack (The Hacker News, SecurityWeek, CrowdStrike) — and a long tail of SharePoint Server fixes, including Critical entries CVE-2026-65665 (RCE), CVE-2026-64921 and CVE-2026-62827 (both elevation of privilege). Administrators are urged to patch internet-facing SharePoint first (Cyber Security News).

The SharePoint story has a second act: Rapid7 disclosed that CVE-2026-55040, a JWT-token authentication bypass patched in July (CVSS 9.1) that lets an attacker enter a SharePoint server "as any user with no valid account," is the first half of an exploit chain — the companion remote-code-execution bug was patched in this month's update, closing an unauthenticated-RCE path against SharePoint Subscription Edition, 2019 and 2016 (Rapid7, Cybernews). Rapid7 noted much of the research was done with the help of an AI agent.

Patch Priority — exploited zero-day + Friday federal deadline

CVE-2026-68820 (Windows AFD/WinSock, exploited) and CVE-2026-20349 (Cisco ASA/FTD, due Aug 14)

Apply the August cumulative Windows update now: CVE-2026-68820 is under active exploitation for privilege escalation and carries a KEV federal due date of Aug 25 (13 days) (CISA via WindowsForum). The nearest federal deadline, though, is Cisco's: CVE-2026-20349 (CVSS 8.6) is being exploited to remotely crash ASA/FTD firewalls running Remote Access SSL VPN — unauthenticated, no user interaction — and FCEB agencies must remediate by Friday, Aug 14 (2 days) (Cisco advisory cisco-sa-asaftd-vpn-dos-dzv4mQFF; BleepingComputer, The Hacker News).

And if you run self-hosted Metabase: the exploited SQL injection is now CVE-2026-72898 (CVSS 10.0), KEV-listed Aug 11. Patch to x.58.24 / x.59.21 / x.60.17 / x.61.11 / x.62.9 / x.63.5 or block /api/session/reset_password (Metabase advisory; Wiz, IONIX).

Threat Actor Spotlight

Sandworm — still the name behind Poland's energy intrusions

ESET ties the late-2025 attack wave on Poland's energy system to the Russia-aligned Sandworm APT with medium confidence, citing "a strong overlap with numerous previous Sandworm wiper activity we analyzed" (ESET via Security Affairs). CERT Polska's disclosure remains the OT case study of the year: a compromised Fortinet VPN at a wind farm, an SSH tunnel through a Teltonika cellular router into a distribution operator's private APN, and hands on a Wago PLC inside a heat plant that serves ~50,000 residents — turbine and water treatment shut down, with ~30 renewable-energy facilities and a second CHP plant hit the same day (BleepingComputer, Help Net Security, The Record). The group’s social-engineering arm is active right now, too: CERT-UA says UAC-0145, a Sandworm subgroup, has been posing as recruiters on job-search sites since May 2026 — one persona is an IT company called "ATLAS Business Group" — steering Ukrainian system administrators and IT specialists into Telegram chats and pushing a VPN client that can run commands on their machines (CERT-UA via The Hacker News). On the state-actor board this week, Check Point ties exploitation of the new Windows zero-day CVE-2026-68820 to North Korea's Operation Dream Job — attackers used it to plant a kernel-mode rootkit (SecurityWeek).

Breaches & Incidents

Exploited

Attackers turn a just-patched VMware vCenter flaw into persistent remote access

Threat actors are actively exploiting CVE-2026-59310 (CVSS 9.8), a directory-traversal flaw in Broadcom’s VMware vCenter Server patched late last month. German firm QUIRSO, working an incident response, found path-traversal activity followed by a malicious cron job running reverse_ssh to keep access; compromised systems first contacted attacker domains on Aug 3 — five days after the patch shipped (The Hacker News). The flaw is not yet in CISA’s KEV catalog as of this edition.

Browser

737 fake Chrome VPN extensions route entire browser sessions through one proxy network

Socket researchers caught 737 free VPN and proxy extensions — published across at least 40 Chrome Web Store developer accounts, with 75,486 installs — mainly targeting Russian-speaking users seeking access to blocked services. 274 impersonate 66 established brands, including Proton VPN, NordVPN, Surfshark, ExpressVPN, Cloudflare’s 1.1.1.1 and Google’s Outline, and 520 of the 522 in the bulk corpus route users’ entire browser traffic through the same SOCKS5 infrastructure (researcher Kush Pandya, via The Hacker News).

AI

API flaw let weaker AI models decode stronger models’ hidden reasoning — and leak secrets

A newly disclosed weakness in how OpenAI, Anthropic and Google carried encrypted reasoning blocks between API calls let researchers replay a block from one session into another — even handing it to a weaker model in the same family — to recover hidden reasoning and secrets from session logs, including API keys and passwords. The team behind "Stealing Reasoning Traces from Proprietary LLM APIs" demonstrated four abuse paths and decoded 315,320 thinking blocks across 6,708 public agent trajectories (The Hacker News).

0-day

"ShieldBreak": the Defender exploit granting SYSTEM still has no fix

The researcher known as Chaotic Eclipse (aka Nightmare Eclipse) released ShieldBreak right after August’s Patch Tuesday, calling it a full patch bypass of RoguePlanet (CVE-2026-50656, CVSS 7.8) — a race condition in the Malware Protection Engine (mpengine.dll) that Microsoft fixed in July, almost a month after disclosure. The PoC elevates to SYSTEM on fully patched Windows 10, 11 and Windows Server, with a claimed 100% success rate on Windows 11 25H2 and Server 2025 — and no fix is available yet (BleepingComputer, The Hacker News, Cybernews, UT-Austin RSOC). It is the same researcher behind the LegacyHive, BlueHammer, RedSun, YellowKey, GreenPlasma, MiniPlasma and UnDefend disclosures since April.

Ransomware

DeadLock’s blockchain-backed extortion machine now counts 96 claimed victims

Microsoft’s teardown of DeadLock — a Rust-based double-extortion operation active since July 2025 — details recovery infrastructure that stores configuration on the Polygon blockchain, rotates proxy addresses through smart contracts so takedowns have no domain to seize, and routes victim negotiations through the onion-routed Session messaging network. The group has claimed 96 victims as of this month, most in Italy, Spain, Poland, Türkiye and the U.S., and Microsoft has seen it deployed by multiple actors — including an affiliate of the Lynx and INC ransomware operations (Microsoft Security Blog, The Hacker News, BleepingComputer).

NewReport

Blue Report 2026: defenses recovered at the edge — and collapsed inside

Picus Labs' new Blue Report, built from more than 338 million real attack simulations run in client production environments in the first half of 2026, finds average prevention effectiveness climbed from 62% to 69% — matching its 2024 peak — and logging hit a four-year high of 58%. The catch: the recovery is happening almost exclusively at the perimeter. Once that line is crossed, defenses "turn soft," and are softest against the quiet moves — reconnaissance and credential theft — that precede every serious breach (Picus Labs via The Hacker News).

NewBotnet

Kimwolf v7 makes DDoS traffic look like a real browser — and hides its C2 on ENS and Tor

Palo Alto Networks Unit 42 detailed a new version of the Kimwolf/AISURU Android and IoT botnet that adds an HTTP/2-based DDoS flood constructing complete browser fingerprints, making attack traffic far harder to distinguish from legitimate browsing. v7 also hardens its command-and-control against takedown with a tiered scheme — Ethereum Name Service lookups, a hard-coded Tor .onion service and a local clearnet-to-Tor proxy — while stripping out all scanning, exploitation and brute-force functionality (Unit 42 via The Hacker News).

KEV

Metabase SQLi: five companies breached, connected database credentials exposed

The exploited Metabase zero-day, CVE-2026-72898 (CVSS 10.0), was added to CISA’s KEV catalog Aug 11. TechTimes reports the SQL injection breached five companies and exposed all connected database credentials; n8n has confirmed 136 customer records taken, and Framework, Tally and Kilo Code were named earlier. Patch to x.58.24 / x.59.21 / x.60.17 / x.61.11 / x.62.9 / x.63.5 or block /api/session/reset_password (Metabase advisory; Wiz, IONIX, runZero).
