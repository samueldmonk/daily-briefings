Top Story

Patch Tuesday lands heavy: 394 fixes, three zero-days — and the WinSock driver flaw is already being exploited

Microsoft's August security release, published Tuesday, addresses 394 vulnerabilities across Windows, Office, SharePoint Server, Azure services, .NET, PowerShell and Visual Studio Code — including three zero-days (Cyber Security News; SecurityWeek's count runs to 421 CVEs, BleepingComputer's to 400, depending on what's included). The urgent one is CVE-2026-68820, a use-after-free in the Windows Ancillary Function Driver for WinSock (afd.sys) that Microsoft flags as exploited in the wild for privilege escalation; CISA added it to the KEV catalog the same day. Attribution has hardened overnight: Check Point researchers report the flaw has been exploited by North Korean attackers to deploy a kernel-mode rootkit in a new wave of Operation Dream Job (SecurityWeek). The other two zero-days were publicly disclosed but not marked exploited: CVE-2026-72971, a tampering flaw in the Windows Container Isolation driver (unionfs.sys), and CVE-2026-62832, an elevation-of-privilege bug in the Windows User Profile Service (Cyber Security News).

Beyond the zero-days, the release carries a Critical remote-code-execution flaw in the Azure Attestation and Device Health Attestation services (CVE-2026-71331), a Critical Microsoft QUIC flaw (CVE-2026-62815) that an unauthenticated attacker can trigger with a crafted packet — code execution with no user interaction (SecurityWeek, CrowdStrike) — and a long tail of SharePoint Server fixes, including Critical entries CVE-2026-65665 (RCE), CVE-2026-64921 and CVE-2026-62827 (both elevation of privilege). Administrators are urged to patch internet-facing SharePoint first (Cyber Security News).

The SharePoint story has a second act: Rapid7 disclosed that CVE-2026-55040, a JWT-token authentication bypass patched in July (CVSS 9.1) that lets an attacker enter a SharePoint server "as any user with no valid account," is the first half of an exploit chain — the companion remote-code-execution bug was patched in this month's update, closing an unauthenticated-RCE path against SharePoint Subscription Edition, 2019 and 2016 (Rapid7, Cybernews). Rapid7 noted much of the research was done with the help of an AI agent.

Patch Priority — exploited zero-day + Friday federal deadline

CVE-2026-68820 (Windows AFD/WinSock, exploited) and CVE-2026-20349 (Cisco ASA/FTD, due Aug 14)

Apply the August cumulative Windows update now: CVE-2026-68820 is under active exploitation for privilege escalation and carries a KEV federal due date of Aug 25 (13 days) (CISA via WindowsForum). The nearest federal deadline, though, is Cisco's: CVE-2026-20349 (CVSS 8.6) is being exploited to remotely crash ASA/FTD firewalls running Remote Access SSL VPN — unauthenticated, no user interaction — and FCEB agencies must remediate by Friday, Aug 14 (2 days) (Cisco advisory cisco-sa-asaftd-vpn-dos-dzv4mQFF; BleepingComputer, The Hacker News).

And if you run self-hosted Metabase: the exploited SQL injection is now CVE-2026-72898 (CVSS 10.0), KEV-listed Aug 11. Patch to x.58.24 / x.59.21 / x.60.17 / x.61.11 / x.62.9 / x.63.5 or block /api/session/reset_password (Metabase advisory; Wiz, IONIX).

Threat Actor Spotlight

Sandworm — still the name behind Poland's energy intrusions

ESET ties the late-2025 attack wave on Poland's energy system to the Russia-aligned Sandworm APT with medium confidence, citing "a strong overlap with numerous previous Sandworm wiper activity we analyzed" (ESET via Security Affairs). CERT Polska's disclosure remains the OT case study of the year: a compromised Fortinet VPN at a wind farm, an SSH tunnel through a Teltonika cellular router into a distribution operator's private APN, and hands on a Wago PLC inside a heat plant that serves ~50,000 residents — turbine and water treatment shut down, with ~30 renewable-energy facilities and a second CHP plant hit the same day (BleepingComputer, Help Net Security, The Record). On the state-actor board this week, Check Point ties exploitation of the new Windows zero-day CVE-2026-68820 to North Korea's Operation Dream Job — attackers used it to plant a kernel-mode rootkit (SecurityWeek) — and Russia's Operation Matryoshka disinformation campaign is pushing AI-faked videos at Germany's election cycle (Cybernews).

Breaches & Incidents

New0-day

"ShieldBreak": Defender exploit grants SYSTEM on fully patched Windows

A researcher going by Nightmare Eclipse released a Microsoft Defender exploit dubbed ShieldBreak right after August's Patch Tuesday, calling it a full patch bypass of the RoguePlanet flaw (CVE-2026-50656) Microsoft fixed in July. The PoC can elevate to SYSTEM on fully patched Windows 10, 11 and Windows Server, with the researcher claiming a 100% success rate on Windows 11 25H2 and Server 2025 — and no fix is available yet (BleepingComputer, Cybernews, UT-Austin RSOC). It is the same researcher behind the LegacyHive, RoguePlanet, BlueHammer, RedSun, YellowKey, GreenPlasma, MiniPlasma and UnDefend disclosures since April.

Ransomware

DeadLock hides its extortion machine on the blockchain

Microsoft has published a teardown of DeadLock, a Rust-based ransomware operation running double extortion since July 2025 — with a twist: its recovery infrastructure stores configuration on the Polygon blockchain, uses smart contracts to rotate proxy addresses without touching any seizable domain, and routes victim negotiations through the onion-routed Session messaging network, making takedowns far harder (Microsoft Security Blog, The Hacker News, BleepingComputer). TechTimes counts 80-plus claimed victims, concentrated in Italy, Spain, Poland, Türkiye and the U.S.

Breach

Levi Strauss: three phone calls, no exploit

Levi's disclosed in an Aug 7 regulatory filing that attackers socially engineered three employees into surrendering access to their company-issued computers and exfiltrated corporate files. The activity is linked to UNC6671, a group that vishes staff by impersonating IT-helpdesk workers and steering them to spoofed login pages. The company says no customer data was affected and expects no material impact (Cyber Security News, Rescana, Cyber Magazine).

KEV

Metabase SQLi gets its CVE — and a five-company victim list

The exploited Metabase zero-day is now CVE-2026-72898 (CVSS 10.0), added to CISA's KEV catalog Aug 11. TechTimes reports the SQL injection breached five companies and exposed all connected database credentials; n8n has confirmed 136 customer records taken, and Framework, Tally and Kilo Code were named earlier (BleepingComputer, Help Net Security). Wiz has published a technical teardown, and runZero shipped detection queries for exposed instances (versions 0.58–0.63.4 / Enterprise 1.x, per IONIX).

ICS

Poland's heat-plant OT intrusion: the private-APN playbook

CERT Polska's December attack chain — Fortinet VPN at a wind farm → Teltonika router SSH tunnel → private cellular APN → OT network → Wago PLC — shut down a steam turbine and water treatment at a CHP plant serving ~50,000 residents, with recovery starting while intruders were still inside; customers never lost heat. A misconfigured APN that let arbitrary devices talk to each other made the crossing possible (BleepingComputer, Help Net Security, SC Media).

Disinfo

Operation Matryoshka aims AI-faked videos at Germany's election

Russia's Matryoshka disinformation network is circulating fabricated videos targeting the German election cycle, part of a pattern of impersonating legitimate media and institutions to launder false narratives (Cybernews). It lands alongside a heavier state-actor week: an exploited Windows zero-day tied to Lazarus and fresh KEV activity across three vendors.
