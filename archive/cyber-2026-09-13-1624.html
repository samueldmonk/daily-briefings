Top Story

The biggest Patch Tuesday ever shipped a wormable DNS flaw — and broke Remote Desktop on the way out

Microsoft’s September 2026 Patch Tuesday is the largest monthly security release in the company’s history: 973 CVEs with detailed severity data, 113 rated Critical and 860 Important — nearly double August’s count, the largest month-over-month jump on record (Tenable; Trinetri). One outlet renders the total as “974+”; both figures are printed and neither is averaged.

The standout is CVE-2026-69730, a CVSS 9.8 remote code execution flaw in Windows DNS Server: an unauthenticated remote attacker sends a crafted packet to exploit a use-after-free and achieve code execution. It is one of twenty wormable vulnerabilities in the set, and is described as a “spiritual successor to SigRed.” Two further flaws are already being exploited in the wild: CVE-2026-85880, a heap-based buffer overflow in Windows ALPC, and CVE-2026-81963, privilege escalation in the Windows Update Stack.

The same cycle is causing damage of its own. KB5122876 (Server 2019), KB5122882 (Server 2022) and KB5122871 (Server 2025), released 8 September, are breaking Remote Desktop Services: servers run normally for a few hours, then RDP connections start failing, existing sessions cannot disconnect or log off, and new attempts hang. Admin debugging points to a possible deadlock between Remote Desktop and the Local Session Manager, stuck at RDPSERVERBASE!WDLIB_Close with no timeout to recover. Microsoft says it is investigating; as of 10 September there was no out-of-band fix and no timeline (BleepingComputer).

Patch Priority

Do this first — the deadline has already passed

CVE-2026-20079 — Cisco Secure Firewall Management Center (FMC) Software — CVSS 10.0. An unauthenticated, remote attacker can bypass authentication and execute script files on the device to obtain root. Cisco became aware of active exploitation in August 2026. CISA placed it in the KEV catalog with an FCEB deadline of 12 September 2026 — OVERDUE by 1 day.

Cisco Talos has tied post-compromise activity to three separate clusters, including one linked to Sandworm and one associated with Qilin ransomware. If an FMC appliance was internet-reachable before 12 September, patching is necessary but not sufficient — treat it as a compromise investigation. The next deadline after this one is GitLab CVE-2026-85706, due 14 September — 1 day left.

Threat Actor Spotlight

MobileNew

The Mantax OTAX operators — Indonesian double extortion, on a phone

Zimperium’s zLabs has attributed Mantax OTAX to Indonesian threat actors targeting users in Indonesia. It is Android ransomware with spyware built in: it encrypts files, locks the screen and pushes victims into a chat with the attackers, while quietly exfiltrating messages, photos and credentials.

The collection list is unusually broad — lock-screen PINs, SMS, one-time passwords, browser history, contacts, call logs, installed apps, Google account details and location; it can shoot stills from front and rear cameras, watch WhatsApp and Telegram activity, and record the screen via Android’s MediaProjection API.

Delivery is malicious APKs hosted outside Google Play, pushed by phishing and social engineering. On install it requests device administrator rights — a prompt that openly lists wiping all data, changing the screen lock, locking the screen and disabling cameras. Its command-and-control is resilient by design: the active C2 domain is fetched from a GitHub repository, so the operators can pivot the moment infrastructure is blocked.

Breaches & Incidents

Supply chainNew

Trezor: 347,000 addresses phished through a breach at Brevo

On 9 September an unauthorised actor reached Brevo, Trezor’s third-party marketing platform, in an incident affecting 120 Brevo accounts, and used it to send mail from customer accounts including Trezor’s. The phishing ran to Trezor’s opt-in newsletter list of roughly 347,000 addresses; 2,500 users clicked the embedded link. Subject line: “Critical Security Alert: STM32 Entropy Vulnerability” — a fabricated hardware flaw in the STM32 microcontrollers inside Trezor devices, said to let attackers brute-force seeds, pushing recipients toward an app that would steal wallet backup seeds. Trezor took the domain down within 20 minutes; no other Trezor system was touched.

AvailabilityNew

September’s Windows Server updates are knocking out RDS

Not an attack, but an operational outage with the same blast radius. KB5122876 / KB5122882 / KB5122871 (Server 2019 / 2022 / 2025, released 8 September) leave servers healthy for a few hours, then Remote Desktop connections begin failing and some machines need a hard reset. Microsoft is investigating; no out-of-band patch as of 10 September. The awkward part: these are the security updates.

ExtortionNew

Claimed victims: FulcrumSec’s “Hardcoded Horrorshow”, and Settra’s September run

Per ransomware-tracking listings read this run, the extortion group FulcrumSec continues finding hardcoded credentials in public-facing IT infrastructure and exploiting them in a campaign it calls “Hardcoded Horrorshow”, counting Novo Nordisk among its victims. Separately the Settra group claims Hansler Smith Limited (Canada), Teletek Structures Inc. and the U.S. medical-billing firm MedEvolve, threatening to leak data. These are attacker claims carried by tracking feeds — no company confirmation was reached this run, and none is implied.

MobileNew

Mantax OTAX: ransomware, spyware and harassment in one APK

The campaign behind this edition’s spotlight is itself the incident. Beyond encryption and theft, victims are spammed and harassed into a chat with the operators — extortion pressure applied through the device it already controls. Distribution is sideloaded APKs; the entry point is a person, not a perimeter.
