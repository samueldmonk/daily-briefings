Top Story

A CVSS 10.0 Oracle flaw is being exploited in the wild — and the federal deadline to fix it passed six days ago

CISA added CVE-2026-21962 to the Known Exploited Vulnerabilities catalog on August 24, citing evidence of active exploitation. The flaw is an improper access control weakness in Oracle HTTP Server and the Oracle WebLogic Server Proxy Plug-in, carries a CVSS score of 10.0, and lets an unauthenticated attacker with network access over HTTP achieve unauthorized creation, deletion or modification of critical data — or complete access to all data reachable through the plug-in, in CISA’s own wording.

Oracle shipped patches back in January 2026. What changed is who is using it. GreyNoise, CloudSEK and SOCRadar have all reported exploitation activity, and The Hacker News reports the CVE is among several exploited by a China-linked threat actor in attacks on government and commercial infrastructure across more than 100 countries to deliver the SNOWLIGHT downloader.

Under Binding Operational Directive 26-04, Federal Civilian Executive Branch agencies were directed to apply fixes by August 27, 2026. That date is six days past. If you run WebLogic and treated a January patch as optional, this is the item to pull forward.

⚑ Patch Priority — today, September 2

CVE-2026-64849 — MLflow server-side request forgery, CVSS 9.3, all versions before 3.15.0. Unauthenticated. An attacker who can reach the MLflow Tracking Server can force it to issue HTTP requests to arbitrary internal cloud metadata endpoints and extract what comes back. In confirmed incidents attackers exfiltrated live cloud credentials and used them to enumerate cloud resources, deploy cryptominers and establish persistence by creating new IAM users and roles.

KEV-added August 19; the federal remediation deadline is TODAY, September 2, 2026, under BOD 26-04. Upgrade to MLflow 3.15.0 or later. If you cannot upgrade today, take the Tracking Server off any network path that reaches your metadata service.

This box names MLflow rather than the CVSS 10.0 Oracle flaw above because MLflow’s clock runs out today. The Oracle deadline (August 27) is already overdue and is treated here as an escalation, not a countdown. Both deadlines match the CISA KEV & Federal Deadlines section below exactly.

Threat Actor Spotlight

State-linked100+ countries

The China-linked operator behind SNOWLIGHT

The Hacker News reports that CVE-2026-21962 is among several vulnerabilities exploited by a China-linked threat actor in attacks targeting government and commercial infrastructure across more than 100 countries, used to deliver the SNOWLIGHT downloader.

CloudSEK’s honeypot telemetry, cited in the same reporting, found the same infrastructure also hammering a small set of older WebLogic remote-code-execution flaws — CVE-2020-14882/14883, CVE-2020-2551 and CVE-2017-10271 — and concluded that attackers “continue to rely on a small set of highly-effective, simple-to-exploit vulnerabilities to compromise WebLogic environments.” The lesson is unglamorous: the old holes are still the ones being walked through.

Attackers breached roughly 5,000 Dropbox accounts using nothing but victims’ email addresses, creating new Lenovo IDs to bypass password sign-ins — an identity-federation abuse rather than a credential compromise.
