Top Story

OpenAI ships the first model it rates “critical” for cyber capability — and hands it to defenders first

OpenAI has unveiled GPT-6 Astra, a frontier model the company says can identify zero-day vulnerabilities and build working proof-of-concept exploits during authorized security testing. It is the first model OpenAI has designated “critical” for cybersecurity under its Preparedness Framework.

The benchmark number is the headline. On ExploitBench — which measures whether a model can turn a known software vulnerability into a working exploit — Astra scored 100%, against 78.5% for GPT-5.6 Sol, its predecessor as OpenAI’s frontier cyber-capable model. In exploit-development testing against flaws from July and August 2026, Astra found two zero-day vulnerabilities in software the company does not name, and posted substantially higher arbitrary-code-execution rates than Sol. OpenAI says both are being disclosed to the maintainers.

What ships is deliberately narrower than what was tested. The released version is limited to secure code review and patching and refuses prompts asking it to build proof-of-concept exploits. Rather than push it to every ChatGPT user, OpenAI is releasing it first to cybersecurity defenders through its Daybreak Blue program.

WHAT THIS DOES NOT SAY. No source fetched this run reports Astra being misused, names the two zero-days or the affected software, or gives a Daybreak Blue participant count — and none is asserted here. The 100% and 78.5% figures are OpenAI’s own benchmark results as reported; they are not an independent evaluation.

Patch Priority

CVE-2026-83548 + CVE-2026-83549 — SonicWall SMA1000 — chain to unauthenticated RCE — due September 5, 2026 (1 day left)

New this run, and it raises the stakes on this pair. Rapid7 reports that the two SonicWall SMA1000 flaws can be chained to achieve unauthenticated remote code execution on affected appliances. CVE-2026-83548 is the pre-authentication server-side request forgery, carrying a CVSS v3.1 base score of 10.0; CVE-2026-83549 is the OS command injection. SonicWall disclosed both on September 1 and says they are being actively exploited in the wild; hotfixes were released the same day. Affected: the 6210, 7210 and 8200v, including all supported hypervisor deployments.

Both are on the seven-CVE batch CISA added on September 2, both sit in the sub-group due September 5, and that is the nearest deadline on this page. Patch this first.

This date is the same one used in the KEV section and the countdown below. Until this run the page carried 83548 alone as Patch Priority because no chain was sourced; the chain is now sourced, so the entry names both.

NO CISA DIRECTIVE IS NAMED ON THIS PAGE. For a sixth consecutive run, no directive number has been confirmed from a CISA page. cisa.gov itself was not fetched this run; the September 2 addition and the product list were re-confirmed through CISA’s own alert URL and corroborating trackers. So the due dates are stated as published and reported, without asserting the mechanism behind them.

Threat Actor Spotlight

Living off trusted software

The Faronics Deploy operator — a signed installer as the entire intrusion

Documented by Huntress and reported in early September. Phishing emails disguised as invoices, tax documents, financial records and event invitations prompt the victim to download and run a legitimate, signed Faronics Deploy installer dressed up as an Adobe document, a reader app or a plugin update. On install, the machine enrols itself into a Faronics deployment the attacker controls, handing them remote script execution at administrative privilege. From there the operator chains to ScreenConnect, so the remote-access traffic rides inside a workflow the defender already trusts.

Scale and outcome: more than 457 endpoints encountered Faronics-related lures over one month. Malicious activity dropped significantly from August 21, which Huntress reads as the vendor’s countermeasures working; Faronics has since added detection and blocking for fraudulent account registrations, including ones using impersonated organisations.

CARRIED, NOT RE-FETCHED. Huntress was not fetched again this run; this entry stands on the sourced record established when it was first published and is held here rather than replaced, because no newer actor was returned this run. It is not tagged New.

IoTPersistence

Operation CameraSwarm — 14,000+ Dahua cameras, one operator

At least 14,530 Dahua IP cameras compromised by a single operator over 35 days (17 June – 22 July 2026) along three concurrent paths: brute force on TCP 37777 (12,324 unique IPs), auth bypass via CVE-2021-33044 / CVE-2021-33045 (1,923 cameras), and a cloud-relay attack on 283 cameras behind NAT using only serial numbers and SDK credentials embedded in Dahua’s own applications. The backdoor account p2pwn / p2password survives an admin password change and, on most affected firmware, a factory reset. Concentrated in Ukraine and Russia.

macOSInfostealer

Fourteen fake macOS installers dropping a credential-stealing RAT

Mac users are being targeted with 14 fake application installers that present as familiar software and instead launch a credential-stealing remote-access trojan. Re-confirmed in this run’s daily roundup. No victim count is stated in any source fetched this run, so none is published.

CISA KEV & Federal Deadlines

  • Added September 2, 2026 — seven vulnerabilities. CVE-2026-9586 (Sangoma Switchvox SQL injection), CVE-2026-48710 (Kludex Starlette HTTP request/response smuggling), CVE-2026-49869 (Kestra OSS OS command injection), CVE-2026-59822 (BerriAI LiteLLM improper authentication), CVE-2026-82329 (JFrog Artifactory improper authentication), CVE-2026-83548 (SonicWall SMA1000 SSRF), CVE-2026-83549 (SonicWall SMA1000 OS command injection). All seven were returned again this run, and the addition date is anchored to CISA’s own alert URL, which carries the stamp /2026/09/02/.
  • Remediation due September 5, 2026 — 1 day left — for five of the seven: CVE-2026-83548, CVE-2026-83549, CVE-2026-9586, CVE-2026-82329 and CVE-2026-49869. This date has been corroborated by four independent trackers across today’s editions (Rapid7, Qualys ThreatPROTECT, Sophos, SOCRadar), each citing the September 2 addition.
  • Remediation due September 16, 2026 — 12 days left — for the remaining two: CVE-2026-48710 and CVE-2026-59822. Five plus two is seven.
  • No new KEV additions on September 3 or September 4 were returned by any source fetched this run. One aggregation this run headed the same seven-flaw batch “September 3”; CISA’s own alert URL says September 2, and that is the date used here and in every countdown above.
  • Not on the September 2 list, and no deadline found: PaperCut MF/NG appears on a “10 CVEs under active exploitation” roundup for September 3 but was not among the seven, and no remediation date for it was returned. No date is asserted. The same applies to CVE-2026-14894 (Super Forms) and CVE-2026-60004 (Gitea), both reported as exploited but neither returned with a deadline this run.
