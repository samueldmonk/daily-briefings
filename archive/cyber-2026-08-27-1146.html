Top Story

Updated · 11:35Deadline todayKEV

Federal agencies have until today to patch a maximum-severity Oracle WebLogic proxy flaw

CISA added CVE-2026-21962 to its Known Exploited Vulnerabilities catalog on August 24, confirming that attackers are using the flaw against Oracle HTTP Server and the Oracle WebLogic Server Proxy Plug-in, and instructed federal agencies to remediate it by August 27 — today.

Oracle rates the vulnerability CVSS 10.0. The attack arrives over HTTP with no authentication, no user interaction and no existing privileges, and lets an attacker access or modify critical data through crafted HTTP requests. The vulnerable components are the WebLogic Server Proxy Plug-in for Apache HTTP Server and for Microsoft IIS, including deployments bundled with Oracle HTTP Server.

A fix has existed since January 20, 2026, when Oracle disclosed and patched the issue in its January Critical Patch Update — roughly seven months before CISA flagged exploitation.

New this run — a second deadline is now confirmed behind it. For four editions this page reported the August 26 KEV batch with no due date, because none had been verified. One now has been: CISA has ordered federal agencies to remediate CVE-2026-8452 in Citrix NetScaler ADC and NetScaler Gateway by Saturday, August 29. Citrix patched the flaw on June 30, 2026, and initially assessed it as denial-of-service only; researchers at watchTowr subsequently demonstrated that successful exploitation can yield remote code execution as root on unpatched appliances, and it is now being exploited in the wild to plant web shells. Fixed builds are 14.1-72.61 (FIPS), 13.1-63.18 and 13.1-37.272. The three-day window is consistent with the per-CVE, risk-based dates BOD 26-04 replaced the old fixed three-week rule with.

Patch Priority

Patch CVE-2026-21962 — Oracle HTTP Server / WebLogic Server Proxy Plug-in — due today, August 27

This is the single most urgent item on the board: maximum severity (CVSS 10.0 per Oracle), unauthenticated and remotely reachable over HTTP, confirmed exploited by CISA, and the BOD-assigned federal remediation date expires today. It still outranks the new Veeam ONE flaw below, which also scores 10.0 but has no reported exploitation and no federal deadline — exploitation plus a deadline beats severity alone. Inventory every Apache HTTP Server and Microsoft IIS instance running the WebLogic proxy plug-in — including the copies bundled inside Oracle HTTP Server — and apply the January 2026 Critical Patch Update.

Then do Citrix. CVE-2026-8452 on NetScaler ADC and NetScaler Gateway is also confirmed exploited — for remote code execution as root, not merely the denial of service Citrix first described — and its federal deadline is Saturday, August 29, two days out. Patch to 14.1-72.61 (FIPS), 13.1-63.18 or 13.1-37.272. It ranks second today only because Oracle's clock runs out first.

Threat Actor Spotlight

Cl0pData-theft extortionCarried

Cl0p is still publishing victims from its PTC Windchill campaign

The Cl0p ransomware group has been exploiting CVE-2026-12569, a critical improper-input-validation flaw in PTC's product lifecycle management platforms Windchill and FlexPLM. The bug carries a CVSS 9.8, stems from deserialisation of untrusted data, and affects releases prior to 11.0 M030. Operators deploy JSP webshells to exfiltrate data rather than encrypt it.

As of August 19, the group had named more than 40 organisations on its leak site, including Shell, Philips, Fiserv, Zebra, Mindray and Largan Precision. Extortion emails are sent from randomly compromised accounts to hundreds of users inside each victim. Targeted sectors include manufacturing, automotive, aerospace and retail. (SecurityWeek, BleepingComputer, The Hacker News)

Breaches & Incidents

New · 11:35Operational impact

Boston Scientific cannot process or ship customer orders after an August 25 attack

Medical-device maker Boston Scientific is investigating an August 25 cyberattack that has disrupted operations across its global footprint. The company detected the intrusion on Monday; it triggered a network outage affecting several IT operating systems and business applications, and has cut off the company's ability to process and ship customer orders. Boston Scientific disclosed the incident in an 8-K filing with the SEC, activated its incident response plan and is working with third-party cybersecurity experts. Thousands of staff at its Irish plants have been sent home to work remotely. The disruption is expected to continue, though the company has not said for how long. Boston Scientific has named no attacker and no group has claimed the attack. A claimed attribution was fetched this run and is not published: one summary said the pro-Russian group "Server Killers" had claimed responsibility. A dedicated search of the primary coverage — Cybersecurity Dive, MedTech Dive, Healthcare Dive, Cybernews, HIPAA Journal — states explicitly that no group has claimed it. Attribution to a named group is exactly the kind of claim that must come from the reporting on the incident, not from a general news roundup. (Cybersecurity Dive, MedTech Dive, Cybernews)

Critical vulnerabilityBackup & monitoringCarried

Veeam patches a CVSS 10.0 unauthenticated RCE in Veeam ONE

Veeam has fixed a set of vulnerabilities in Veeam ONE, its monitoring and reporting platform. The most severe, CVE-2026-64633, carries a CVSS v4.0 score of 10.0 — the maximum — because it allows remote, unauthenticated code execution on the Veeam ONE agent host. Affected builds are Veeam ONE 13.0.2.6723 and all earlier version 13 releases; the fix is Veeam ONE 13.1.0.7034, described in Veeam knowledge-base article KB4892. Separately, CVE-2026-65641, CVSS v4.0 9.3, lets a remote unauthenticated attacker force the Veeam ONE service to initiate an SMB authentication attempt — a classic credential-relay primitive; Veeam disclosed it in KB4905, published August 25, 2026, and credited a report via HackerOne. The wider update set also addresses flaws allowing sensitive-file access, database data theft and privilege escalation. No source seen this run reports exploitation in the wild, and neither CVE appears in the KEV additions verified this run, so no federal deadline is stated. (Cybersecurity News, GBHackers, Veeam KB4892 / KB4905)

Data theftHealthcareCarried

Nutex Health discloses data exfiltration in an 8-K

Hospital operator Nutex Health — which runs 28 facilities across 12 US states — told the SEC in a Form 8-K filed August 24 that an unauthorised third party accessed its servers and exfiltrated data that "may be private or confidential." The company is still assessing whether patient, employee, credentialed-provider, business, financial or intellectual-property data was taken. It has engaged external incident-response and forensic specialists, contained the intrusion and notified law enforcement, and says the incident has had no material impact on operations or financial reporting to date. No threat actor has claimed responsibility. (BleepingComputer, SecurityWeek, SC Media)

Data theftHealthcareCarried

CareCloud breach confirmed at 3.7 million people — ten times the original estimate

Digital health company CareCloud has confirmed that more than 3.7 million people were affected by a breach it first believed had hit roughly 350,000; the far larger figure appears on the HHS breach tracker. The company disclosed in early July that it had detected a network intrusion in mid-March, with the attackers inside one of its AWS environments between March 10 and March 16. Stolen data includes names, addresses, Social Security numbers, driver's licence numbers, dates of birth, health-insurance information and medical records, and for a very limited subset, full payment-card information. No cybercrime group has publicly claimed the hack and it is unclear whether a ransom was paid. It now ranks as the fifth-largest theft of health data in 2026. (TechCrunch, SecurityWeek, HIPAA Journal, Malwarebytes)

Note on an earlier omission: this page previously saw a "3,750,000 affected individuals, filed with HHS" figure with no covered entity attached, and dropped it rather than publish an anonymous statistic. It belonged to CareCloud. It is published now that the entity is named.

AI agentsAgent hijackCarried

NVIDIA NemoClaw flaw can hijack an AI agent from a web page — and the advisory is now quantified

A critical vulnerability disclosed in NVIDIA NemoClaw could let an attacker hijack an AI agent after the victim simply visits a malicious website. New this run: NVIDIA published four advisories this week, one of which covers 18 vulnerabilities in NemoClaw and OpenShell — enterprise AI security and runtime products designed to wrap around autonomous AI agents. Two of the 18 are rated critical and can be exploited for code execution, privilege escalation, data tampering, information disclosure and denial of service. Adobe shipped patches in the same window, including critical code-execution flaws in Acrobat Reader, InDesign, InCopy, FrameMaker, Connect, Bridge, Photoshop and Illustrator. No CVE identifier or CVSS score is printed for the NemoClaw agent-hijack flaw — none has been stated in any source seen across this run or the last. No Adobe vulnerability count is printed either: the sources this run give "51 across 5 products" and "55 across 11 products," and two counts that cannot both be right are not averaged into one. The publication day is also given as both Tuesday and August 26 in the same summary, so the page says "this week." (SecurityWeek, The Hacker News)

Ransomware-as-a-serviceCISA advisoryCarried

CISA and the FBI detail Gunra ransomware

CISA released a #StopRansomware advisory (AA26-222A) on August 10, 2026 covering Gunra ransomware, first observed by the FBI in April 2025. As of January 2026 Gunra had launched a formal ransomware-as-a-service affiliate programme on dark-web forums, giving affiliates a management panel and a configurable ransomware builder. Ransom demands run through a customised Tor-based negotiation portal, with exfiltrated data published to a dedicated leak site if victims do not pay. (CISA advisory AA26-222A)
