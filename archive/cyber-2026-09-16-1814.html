Top Story

A CVSS 10.0 in Cisco ISE, found because someone had already been breached

CVE-2026-76460 is an unauthenticated REST API authentication bypass in Cisco Identity Services Engine carrying a CVSS score of 10.0. The flaw stems from insufficient authentication control on an API endpoint: an attacker sends crafted requests straight to an exposed endpoint, bypasses the web management interface entirely, and then executes commands with root privileges. Cisco disclosed it today.

The detail that matters most is how it was found. Cisco discovered the vulnerability while working a TAC support case — meaning at least one enterprise environment was already compromised before anyone knew the bug existed. Cisco directs customers to Release 3.4 Patch 2 (no further action if already running it) or, for anyone on Release 3.3 Patch 6, to Release 3.3 Patch 7.

ISE is the thing that decides who gets onto the network. A pre-authentication root compromise of the gatekeeper is not a lateral-movement problem to be contained later; it is the identity layer itself. CISA added it to the Known Exploited Vulnerabilities catalogue the same day, in a two-CVE alert alongside CVE-2026-87886 (Acronis Backup, incorrect default permissions), with a remediation deadline of 19 September 2026.

Patch Priority — do this first

CVE-2026-76460, Cisco Identity Services Engine. CVSS 10.0, unauthenticated, exploited in the wild, root-level command execution. Upgrade to Release 3.4 Patch 2, or to Release 3.3 Patch 7 if you are on 3.3 Patch 6. The federal remediation deadline is 19 September 2026 — three days from today. If ISE is reachable from an untrusted network, treat this as an active-incident question rather than a patch-window question.

Threat Actor Spotlight

The Gentlemen · active since mid-2025

The fastest-scaling ransomware brand on record

The Gentlemen have claimed nearly 300 organisations across more than 66 countries and 20 industry verticals since surfacing in mid-2025 — a growth curve Halcyon describes as faster than any other group on record. The cadence is the tell: dark-web collection confirmed five new victim postings in five days between 1 and 5 September 2026, roughly one a day at peak, spread across transportation, healthcare and technology. That is not opportunistic smash-and-grab; it is a scalable intrusion pipeline with a staffed back end.

WooCommerce plugin exploited in the wild

Threat actors are exploiting a critical flaw in WooCommerce Wholesale Lead Capture, a premium WordPress plugin with more than 6,000 active installs. Small install base, high-trust position: these plugins sit on storefronts that handle customer and payment data.

Medusa passes 500 critical-infrastructure victims

The FBI, CISA and HHS updated their joint advisory with investigation data current to April 2026: Medusa actors have hit more than 500 victims across healthcare, the defence industrial base, critical manufacturing, government services, IT and financial services since June 2021. The tally is up almost 67% in a year, from the 300-plus reported in the March 2025 advisory. Double extortion; entry is typically unpatched software.

CISA KEV & Federal Deadlines

  • CVE-2026-76460 — Cisco Identity Services Engine. Added 16 September, due 19 September 2026 (3 days left). Catalogued as “Incorrect Use of Privileged APIs”.
  • CVE-2026-87886 — Acronis Backup. Added 16 September in the same two-CVE alert. No source fetched this run states its assigned remediation date, so no countdown is printed.
  • CVE-2026-58704 — Google Pixel, improper authorization. Added 16 September in a separate single-CVE alert. Deadline not stated by any source fetched.
  • Overdue: CVE-2026-20079 (Cisco Firewall Management Center), CVE-2026-19490 (Citrix NetScaler) and CVE-2025-25249 (Fortinet) carried a 12 September 2026 deadline — 4 days overdue.
  • Thirteen CVEs currently carry confirmed active exploitation across Citrix NetScaler ADC and Gateway, Cisco Secure FMC and Secure Email Gateway, Fortinet FortiOS, MikroTik RouterOS, ConnectWise ScreenConnect, GitLab and JFrog Artifactory.
  • Which directive applies. Federal remediation timelines now run under BOD 26-04, “Prioritizing Security Updates Based on Risk”, which replaced the old uniform window with a risk-based matrix. A three-day deadline like the one on the Cisco ISE flaw is normal under that regime, not an error. Note also that KEV entry requires evidence of exploitation — a severe flaw with no confirmed exploitation carries no federal deadline at all.
