Top story

CISA gives federal agencies 72 hours to fix a perfect-10 Oracle bug that has been patchable since January

CVE-2026-21962 carries a CVSS score of 10.0 and sits in Oracle HTTP Server and the Oracle WebLogic Server Proxy Plug-in for Apache HTTP Server and Microsoft IIS. It is an improper access control flaw (CWE-284) that needs no account, no credentials, no user interaction and no existing privileges — an attacker with network access can reach it over HTTP. In CISA’s own words, successful exploitation can result in “unauthorized creation, deletion, or modification access to critical data as well as unauthorized access to critical data or complete access to all Oracle HTTP Server and Oracle WebLogic Server Proxy Plug-in accessible data.” It also carries a scope change, meaning a compromise can reach systems beyond the vulnerable component.

CISA added it to the Known Exploited Vulnerabilities catalog on Monday, August 24, and set the remediation deadline at Thursday, August 27 — a three-day window, which The Register notes is the tightest deadline CISA is authorised to assign under the risk-based timelines in BOD 26-04. Only two other bugs have drawn the same treatment recently: the Ray remote-code-execution flaw added last week, and N‑able’s “god mode” N‑central vulnerability added on August 3.

The uncomfortable part is the timeline. Oracle disclosed CVE-2026-21962 and shipped patches in its January 20, 2026 critical patch update, listing versions 12.2.1.4.0, 14.1.1.0.0 and 14.1.2.0.0 as affected and warning it could be exploited in low-complexity attacks. Attackers did not wait. Vikas Kundu, a cyber intelligence analyst at CloudSEK, ran a high-interaction honeypot posing as a vulnerable WebLogic Server for 12 days between January 22 and February 3, 2026 — shortly after disclosure and after public exploit code appeared — and captured exploitation attempts against this CVE alongside older WebLogic remote-code-execution bugs including CVE-2020-14882/14883, CVE-2020-2551 and CVE-2017-10271. “The overall activity was characterized by high-volume, automated scanning, with tools like libredtail-http and the Nmap Scripting Engine dominating the malicious traffic,” Kundu wrote, describing a broad “spray and pray” approach. CISA’s catalog entry lands seven months after that.

Medusa has passed 500 victims, and the federal advisory on it has been rewritten

The FBI, CISA and the Department of Health and Human Services updated their joint #StopRansomware advisory on Medusa on August 18, 2026, with data drawn from FBI investigations as of April 2026. The headline number moved sharply: Medusa developers and affiliates have now impacted more than 500 victims across critical infrastructure sectors, against the more than 300 the agencies reported in the March 2025 version of the same advisory. Affected industries named include medical, education, legal, insurance, technology and manufacturing, with healthcare, defence, government services, IT and financial services also listed.

The mechanic worth planning for is the clock. Medusa runs a double-extortion model, and the agencies describe a 48-hour window: victims get two days to respond to the ransom note before the group begins contacting them directly and posts the stolen data to a leak site with a countdown timer. That is an incident-response design constraint, not a trivia point — it means the decision-making chain has to be exercised before the note arrives, not after. The agencies’ recommendations are unglamorous and unchanged: patch internet-facing systems, segment networks to limit lateral movement, and block untrusted traffic from reaching remote-access services.

NewActively exploitedWordPressSAML

Attackers are chaining two miniOrange SAML flaws to log in as WordPress administrators — and the paid editions were patched without an advisory

Hackers are attempting to exploit two critical authentication-bypass vulnerabilities in the miniOrange SAML 2.0 Single Sign On plugin for WordPress, chaining them to forge SAML responses and sign in as an administrator. The plugin, from Xecurify, turns a WordPress site into a SAML service provider so users can authenticate through Microsoft Entra ID, Okta, Google Workspace or OneLogin. It ships as a family of seven plugins: a free version with 10,000 downloads and, per the vendor, 30,000 customers across the other six.

How the chain works. CVE-2026-61979 exists because the plugin accepts the signature algorithm from the incoming SAML response instead of enforcing the configured one; an attacker selects HMAC-SHA1, which makes the plugin treat the identity provider’s public RSA key as a shared secret. Since that key is public, the attacker can forge a signature the plugin accepts. CVE-2026-15981 then covers the gap: mo_saml_validate_signature() performs a loose boolean check on the tri-state integer PHP’s openssl_verify() returns, so an error value of −1 evaluates as truthy and a malformed signature passes validation.

The disclosure failure is the reason this is being exploited now. Per Patchstack, both flaws were publicly disclosed and fixed in July — but the vendor’s advisory covered only the free edition, leaving the six paid editions without an alert even though fixes shipped for them too. Because WordPress does not show update warnings for the paid builds, many sites took no action. Patched releases are 5.4.5 (free, single site), 13.0.4 (Premium, single site), 17.06 (Standard, single site), 20.2.8 (Premium/Enterprise/All-Inclusive multisite), 26.0.3 (Enterprise/All-Inclusive single site), 32.0.8 (VIP single site) and 35.0.7 (VIP multisite) — and they must be applied manually.

Confirmed in the wild. On August 16, DigitalOcean blocked an anomalous WordPress administrator session originating outside its trusted network; the investigation found attackers had chained the two flaws to obtain an admin session cookie through the Standard edition, version 16.1.9. Patchstack reports exploitation attempts and opportunistic scanning from six IP addresses across Europe, Africa and the United States, and a public proof-of-concept exploit targeting the free edition is already available, so the pace can rise at any time.

Neither CVE is a KEV entry and neither carries a federal deadline. CVSS caution: BleepingComputer and Patchstack, the two primary write-ups fetched this run, state no CVSS scores; a search summary attributes 9.8 to CVE-2026-15981 and 8.1 to CVE-2026-61979. Those are recorded as reported rather than asserted, because this page’s standing rule is that a severity number comes from the vendor advisory or NVD. Two further CVE identifiers — CVE-2026-19842 and CVE-2026-57807 — surfaced in third-party databases against the same plugin this run; only the pair named in the exploitation reporting is published here.

LoadersClickFixTeams phishing

Two newly named loaders — one hides its shellcode in English words, the other ships seven modules

Carried from the previous edition. The Hacker News reported on August 24 that researchers have flagged two previously unnamed malware families, WordlistLoader and SynkLoader, both of which deliver next-stage payloads and are assessed as likely routes for selling access on to ransomware groups.

WordlistLoader, documented by Gen Digital researcher Vojtěch Krejsa, is an intermediate stage in a chain that ends in Amatera Stealer (also tracked as ACR Stealer or AcridRain). Delivery is a ClearFake campaign using the ClickFix pattern: a compromised website shows a fake CAPTCHA, the victim clicks “I’m not a robot,” a malicious command is placed in the clipboard and the victim is talked into pasting it into the Windows Run dialog. The injected JavaScript is a Base64 blob that pulls further JavaScript from a blockchain smart contract — the EtherHiding technique — so burned URLs can be swapped for fresh ones without touching the compromised site; recent campaigns have staged the payload on the legitimate cdn.jsdelivr[.]net CDN. The loader takes its name from its evasion: the shellcode is stored as a sequence of ordinary English words, one word per byte, and reassembled at runtime, with a variant that uses 16-byte UUID-encoded chunks instead. It also uses a hardware-breakpoint technique to bypass Event Tracing for Windows. The execution chain runs conhost to launch a hidden cmd.exe, mounts a remote WebDAV share with pushd and loads the DLL via rundll32.exe — an approach Microsoft documented in July and which, per Gen Digital, has now replaced the Python-based loaders Microsoft observed in that chain between late April and mid-June 2026.

SynkLoader, documented by Expel researcher Marcus Hutchins, is the one defenders should read closely, because the delivery is internal and the toolkit is broad. It arrives as a Microsoft Teams message from an account on the target’s own onmicrosoft.com default domain, using the display name “IT Service Desk,” which talks the user into installing an MSI hosted on Azure Blob Storage and presented as a “PowerShell Cleaner” — so both the sender and the download location look like Microsoft. The MSI drops a ZIP and a PowerShell script that runs in memory and launches a Python loader; the loader picks one of three hard-coded command-and-control domains, checks in at random and sleeps 90 to 120 seconds between requests. At least seven modules have been identified: a System Profiler C# DLL that collects host, user and Active Directory detail; a persistence module that creates a randomly named scheduled task firing at every logon and daily at 10 a.m.; PhishLocker, which serves a fake Windows lock screen to harvest the login password; TrafficRedirector, a reverse proxy into the local network; an interactive PowerShell RAT shell; StreamMaster, a VNC module for full desktop control; and a status checker reporting which modules are live. Expel does not state the operator’s end goal, but the Active Directory profiling is the tell — that metric matters most to crews pricing a ransom against network size — and the assessment is that the toolkit belongs to a ransomware group or an initial access broker.

Two practical notes for defenders, stated because they are the cheap controls. Both chains begin with a human being persuaded to run something: the ClickFix half dies if users are trained never to paste a clipboard command into the Run dialog, and the SynkLoader half dies if external Teams messaging is restricted and MSI installs from consumer cloud storage are blocked. No CVE is involved in either chain, so neither carries a patch or a federal deadline.

RansomwareClickFix

One operator is running nearly 2,000 hacked WordPress sites as a single criminal network

Check Point Research analyst Jaromír Hořejší, who first came across the StopAndProtect ransomware family in mid-May 2026, traced it back to an operator actively managing close to 2,000 compromised WordPress domains — a rotating pool used to distribute payloads, carry command-and-control traffic and store files taken from victims. Infections start with a fake CAPTCHA on a compromised site, the ClickFix social-engineering pattern, which talks the visitor into running a PowerShell command; that pulls down .NET downloaders and loaders, and those deliver the real toolkit: ransomware, an SMB/USB worm, a lock screen, a VBS spreader, a chat utility and a credential stealer. The detail that matters operationally is that the ransomware is only one component of the kit — the operators sometimes take the files and never encrypt anything, so an environment can be worked over end to end without ever producing the one signal most detection playbooks are tuned for. Microsoft Defender’s own driver can be turned against security software

Check Point Research disclosed a technique that uses Defender’s legitimately signed boot-time remediation driver, BTR.sys, to perform arbitrary kernel-level file and registry operations on Windows 7 through Windows 11 25H2 — exploiting no software flaw and importing no outside driver. Because BTR.sys is a required Windows component, it cannot be added to Microsoft’s Vulnerable Driver Blocklist or blocked with WDAC without breaking Defender itself. Jiří Vinopal presented the research at Black Hat USA 2026 and DEF CON 34 and published a proof-of-concept tool, BTR_CLI, on August 20. Check Point said it found no evidence of real-world use.

Malicious Rust crates ran code at build time

The Rust Project deleted malicious versions of three widely used crates after a compromised maintainer account published releases that added a typosquatted dependency whose build script downloaded and executed a remote payload during compilation. The affected releases — arrayref 0.3.10, internment 0.8.7 and append-only-vec 0.1.9 — were all published August 20 from the same account and removed within 86 to 107 minutes. Because the code sat in a build script, merely resolving the dependency was enough to run it. There is no patched version and no CVE; developers are advised to search ~/.cargo/registry/cache and pin arrayref at 0.3.9 or earlier.

TrendAI, Trend Micro’s enterprise business, identified 14 npm packages posing as calendar and streak utilities that deliver an AI-powered Linux implant dubbed RedC2 4.0. “When the module loads, it locates the bundled binary, marks it executable, and launches it as a detached background process,” the researchers wrote — no install hook required, and a single import anywhere in the dependency graph, even a transitive one, is enough to execute the payload.
