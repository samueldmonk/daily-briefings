Top Story

Shai-Hulud rides again: keyv-linked npm worm poisons 2,234 package versions across twelve organizations — and plants Claude Code and VS Code hooks

A credential-stealing npm worm that first appeared in keyv@6.0.0 on August 4 spread beyond the Keyv and Cacheable namespaces into hundreds of packages across multiple organizations. SafeDep's updated registry-backed count now stands at 2,234 poisoned versions across 444 package names spanning twelve unrelated organizations — among them @ornikar, @deliveroo, @servicetitan, @qlik and Picsart — all republished between 09:35 and 13:18 UTC on August 4 (SafeDep, direct fetch this edition). Four of the core libraries — keyv, flat-cache, file-entry-cache and cacheable-request — see a combined 1,877 million monthly downloads, and flat-cache and file-entry-cache ship inside ESLint, so the reach extends to projects that never installed keyv directly. Aikido places the campaign in the Shai-Hulud malware family, and researchers counted 546 public GitHub repositories created August 4 with the description "Shai-Hulud: Here We Go Again" as likely exfiltration or staging artifacts.

The malicious releases use a preinstall script to run a compiled credential-stealing bundle inside developer and CI environments — harvesting GitHub, npm, cloud, Vault, Kubernetes, database and private-key material, reading GitHub Actions runner memory, then using any available npm publishing access to poison more packages. The poisoned Keyv release even carried valid OIDC/SLSA provenance because it passed through the project's legitimate GitHub Actions release workflow. A second execution path lurks in the repository itself: Claude Code and VS Code hook files that can run the payload once a user trusts the workspace — both editors gate this behind workspace trust, but the files were still on main at reporting time (The Hacker News/SafeDep/Socket).

Response order matters: SafeDep advises removing the malware's credential-revocation watcher before rotating tokens — revocation is the watcher's trigger, and rotating first can run an attacker-supplied local handler. The poisoned keyv and cacheable releases have been unpublished, but "latest" still resolved to a malicious version for most other affected names at SafeDep's update, so upgrading alone may preserve exposure — check lockfiles and resolved versions against the affected list, and treat any machine that executed an affected version as credential-exposed (Socket). npm 12 blocks unapproved lifecycle scripts by default; earlier clients remain exposed.

Patch Priority

Most urgent action today — deadline day

Upgrade N-able N-central to 2026.3.1.7 — the federal deadline is TODAY, Thursday Aug 6 (0 days left)

CVE-2026-18577 (CVSS 8.2, actively exploited since Aug 1, KEV-listed Aug 3) affects all N-central builds prior to 2026.3.1.7. It is a bypass of a prior fix, so systems patched against CVE-2026-18556 are still vulnerable — and CISA has KEV-listed both flaws, signaling active exploitation of each (The Hacker News). Hosted environments are upgraded by the vendor; on-premise deployments need manual remediation (Rapid7). CISA's clock runs out today under BOD 26-04's three-day window (The Register).

Right behind it: the three flaws CISA added this week — Langflow CVE-2026-9198 (CVSS 9.8, unauthenticated RCE on default deployments, fixed in 1.10.1), Apache Tomcat CVE-2026-34486 and N-central CVE-2026-18556 — carry a federal fix-by date of tomorrow, Friday, August 7 (The Hacker News/CISA). Then hunt, don't just patch: review admin accounts, Take Control session logs, newly created Windows services and outbound Cloudflare Tunnel connections (GBHackers).

Threat Actor Spotlight

Mustang Panda — a year inside a VPN's installer

Fortinet FortiGuard Labs has disclosed what it calls a "long-standing supply chain attack" on QuickFox, a VPN and network-acceleration tool built for overseas Chinese users — ongoing since at least August 2025 and attributed to Mustang Panda, a Chinese state-sponsored threat actor. A trojanized Windows installer delivers FDMTP, a backdoor in the group's kit, via a modified Electron renderer HTML file that downloads and runs a JavaScript loader. The loader fingerprints each victim endpoint to decide whether it's a valid target before installing the implant — selective staging that helped the operation stay quiet for a year. Following responsible disclosure, QuickFox has removed the malicious components from its Windows installer (Fortinet via The Hacker News). The lesson pairs with this week's npm worm: both rode legitimate distribution channels users had every reason to trust.

Breaches & Incidents

NewJustice

Ransom Cartel founder gets 16 years

A federal judge in Alexandria, Virginia, sentenced Maksim Silnikau to 16 years in prison on August 5 for creating and running Ransom Cartel, the ransomware-as-a-service operation he stood up in 2021. Between 2021 and 2023, Ransom Cartel conspirators attacked at least 18 companies, including firms in California, New York and Nebraska, and others abroad (DataBreachToday). One of the longer U.S. ransomware sentences on record — a data point for the deterrence debate.

NewRansomware claim

Everest claims 1 TB stolen from Omnicell

Posts by the Everest ransomware group claim the theft of 1 TB of data from Omnicell, a provider of medication-management and pharmacy-automation systems used by healthcare organizations worldwide (DataBreachToday). Kaseya's Week in Breach separately lists Omnicell among the latest cyberattack victims. A leak-site listing is an attacker claim, not a confirmed breach — but the healthcare supply chain exposure if substantiated is significant.

NewAI abuse

OpenAI disrupts a Cambodia scam network run on ChatGPT

OpenAI says it banned a coordinated network of ChatGPT accounts operating from Poipet, Cambodia — a region with extensive ties to scam compounds and human trafficking — that used its models to run investment, romance, gambling and law-enforcement-impersonation schemes. The cluster generated fake personas, translated messages to targets, and even produced social-media ads for "chatter" jobs in Poipet aimed at users in Bangladesh and India, promising an $800 base salary plus a $100 "full attendance" bonus (The Hacker News).

Healthcare

DentaQuest stands as the year's largest healthcare breach: 15 million affected

The May 2026 ransomware attack on dental-benefits giant DentaQuest is confirmed as the largest healthcare data breach reported this year, affecting 15 million individuals (Kaseya's Week in Breach; reconfirmed in this week's breach roundups) — superseding the higher 23M+ leak-site claim from initial reporting. Also in pharma this week: Inotiv notified 9,542 people after an August-disclosed ransomware attack, and Amgen told the SEC cybercriminals potentially stole sensitive data including patient information and R&D files (Tech.co / BrightDefense breach trackers).
