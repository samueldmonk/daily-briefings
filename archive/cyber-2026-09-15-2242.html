Top Story

Microsoft's September patches broke Remote Desktop, and the fix for that is not to uninstall them

Microsoft has confirmed that the September 2026 security updates cause Remote Desktop Services failures on Windows Server. Session hosts on Windows Server 2019, 2022 and 2025 freeze hours after boot; RDP connections stick at "Connecting…" or at "Please wait for the Remote Desktop Configuration"; users cannot log off cleanly. The updates named are KB5122876 (2019), KB5122882 (2022) and KB5122871 (2025).

Microsoft issued Group Policy workarounds and then published out-of-band updates on 14 September. The bind, as the reporting states it, is the reason this leads: rolling the update back restores stability but strips the security fixes shipped in the same package — a package that closed two exploited Windows zero-days and a CVSS 9.8 Remote Desktop Services remote code execution flaw. Administrators who chose stability last week are running unpatched against flaws already being used.

The out-of-band updates are the way out of that trade-off, and applying them is the action item. The broader count for the month is disputed: The Hacker News reports 974 flaws, Tenable's tracker — the only one retrieved in full — gives 964 (104 critical, 860 important), and Senserva publishes 1,169 CVEs across 60 KBs, 118 critical, describing that as Microsoft's own count. All are named rather than averaged.

Patch Priority

GitLab CVE-2026-85706 — CVSS 10.0 — federal deadline was 14 September, now overdue by 1 day

An unauthenticated path traversal in the repository commits API, arising from improper path confinement together with missing authentication checks, permitting arbitrary file reads. GitLab assigned it CVSS 3.1 10.0. Patched in 19.1.8 / 19.2.6 / 19.3.2 on 10 September; exploitation began one day after public disclosure; CISA added it to the KEV catalog on 11 September with a Federal Civilian Executive Branch remediation date of 14 September 2026. Patch, then rotate every secret the file-read could have exposed — a read-only flaw on a source-control server is a credential-disclosure flaw.

This deadline was carried hedged between 14 and 15 September in earlier editions today, because two readings disagreed and cisa.gov returned an empty body on direct fetch. Two independent sources this run — Cybersecurity Dive and a second reading of the KEV catalog — both give 14 September. The hedge is resolved in favour of the 14th, and the banner, this box and the KEV section below all now use that one date.

Threat Actor Spotlight

Russian-speaking · financially motivated

The PivotC2 operator, working Fortinet edge devices

SOCRadar attributes to a Russian-speaking, financially driven actor a campaign weaponising CVE-2025-25249 to deliver PivotC2, a Node.js remote access trojan. A shell script carrying an exploit binary hits a vulnerable FortiGate, establishes a reverse shell and runs a single-line JavaScript command through Node.js; that pulls a second-stage payload, decrypted and executed to deliver the implant. Feature set: interactive shells, file transfers, SOCKS5/HTTP proxy tunnelling, local and remote port forwarding, CIDR-range scanning, and FortiGate-specific configuration harvesting and credential decryption, with an auto-mode flag that runs a predefined command sequence on infection. More than 3,000 IP addresses targeted, 178 devices infected, the majority in the United States; earliest evidence of exploitation dates to July 2026. The detection opportunity is the persistent outbound TLS connection to the C2.

Breaches & Incidents

Healthcare · extortion

McKesson confirms a cyber incident; ShinyHunters claims 284 million records

McKesson discovered the incident on 25 August 2026 and filed a Form 8-K three days later, disclosing unauthorised access to third-party applications and data exfiltration. ShinyHunters says it demanded $55,236,150 with a 72-hour window and that McKesson never answered. The alleged data spans names, addresses, dates of birth, phone numbers, email addresses and Social Security numbers; patient IDs, medical record numbers and Medicaid numbers; and diagnoses, allergies, medications, disabilities, patient notes and appointment details. Important qualifier, stated by the reporting: the 284 million figure refers to rows of raw data, not unique patients.

Financial services

Revolut: fraudulent requests from an authenticated government domain

Attackers sent fraudulent information requests from a legitimate government agency email domain with valid domain authentication. Exposed: date of birth, postal and email addresses, phone numbers, and passport and driving licence copies, possibly also verification selfies, statements and transaction histories. Revolut says "a limited number of customers" were affected and that systems and funds were unaffected. An extortion demand followed. A figure of 680 customers circulated from one low-quality outlet and is refused here — no primary source or major outlet states it.

A note on the count: CISA's own alert page for that date is titled "four known exploited vulnerabilities", while The Hacker News enumerates three, each from a different vendor.     Added 11 September. CVSS 10.0, unauthenticated arbitrary file read. See Patch Priority above; this page uses the 14 September date in all three places it appears.

    CVE-2026-75650 (Adobe Commerce and Magento), CVE-2026-81963 (Microsoft Windows link following), CVE-2026-85880 (Microsoft Windows heap-based buffer overflow) and CVE-2026-86218 (N-able N-central static code injection).
