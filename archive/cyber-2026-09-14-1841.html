Top Story

PaperCut NG/MF · KEV deadline 14 September 2026

A print server is the day’s worst breach: 395 organisations compromised, and the federal clock runs out today

Two PaperCut NG/MF flaws chained together give an unauthenticated attacker remote code execution, and they have already been used at scale. Researchers have identified 440 compromised PaperCut server instances at 395 distinct organisations across 48 countries. 204 of those 395 were schools or universities — print management is exactly the kind of service that sits inside a campus network, is reachable from too many places, and is watched by nobody.

The chain is CVE-2026-81578 (CVSS 8.8), an improper-access-control bug in the web management interface that removes the need to authenticate, plus CVE-2026-82078 (CVSS 9.4), an unsafe dynamic class-loading flaw in the database connection utilities that lets an attacker manipulate configuration parameters and run arbitrary Java bytecode from the application classpath as the PaperCut server process.

CISA added both to the Known Exploited Vulnerabilities catalog on 31 August 2026 and set the federal remediation date at 14 September 2026 — today. PaperCut has since replaced three rounds of emergency patches with full maintenance releases 26.0.5, 25.0.13 and 24.1.10. Given confirmed intrusions at this volume, patching an instance that was internet-facing closes the door but answers nothing — the question is whether anyone already walked through it.

Patch Tuesday · 8–14 September 2026

Also this week: Microsoft’s biggest patch day ever, with two zero-days already being exploited

Microsoft’s September 2026 Patch Tuesday is a record. Counts differ by how vendors tally: 966 flaws (BleepingComputer, Windows Report), 964 CVEs (Tenable, Malwarebytes) and 974 (SecurityWeek, The Hacker News); a sixth tally read this run puts it at 1,169 CVEs, the highest of any count seen and one nothing read reconciles against the others; Computerworld counts 963 CVEs requiring customer action, 106 of them critical. Tenable breaks its 964 into 104 rated critical and 860 important.

Two of them were being exploited before the fix shipped. CVE-2026-81963 is an elevation-of-privilege bug in the Windows Update Stack — an improper link-resolution (“link following”) defect that yields SYSTEM. Seven Windows Update Stack EoP flaws have been patched since 2022; this is the first exploited as a zero-day. CVE-2026-85880 is a heap-based buffer overflow in Windows Advanced Local Procedure Call (ALPC), also local-to-SYSTEM — the first ALPC bug in a Patch Tuesday since April 2023. Neither grants remote access on its own, but SYSTEM is exactly what an intruder who already has a foothold from phishing or stolen credentials wants next. Both are on CISA’s exploited-vulnerabilities catalog, added 8 September.

Separately, Microsoft has confirmed that the September updates cause Remote Desktop Services failures on Windows Server systems — a detail worth knowing before a rushed weekend rollout.

Threat Actor Spotlight

Red Heron

A suspected Chinese crew that turned a public proof-of-concept into an automated repository-stealing framework in days.

Red Heron has been tied to the rapid exploitation of CVE-2026-60004, a CVSS 9.8 remote code execution flaw in Gitea that lets an attacker with ordinary write access to a repository run arbitrary shell commands as the Gitea OS user. Within days of the July 2026 disclosure the group had converted public exploit code into an automated Python framework, exp_enhanced.py, that registers accounts, exploits servers and pulls down repositories. Reporting this run puts the scanning at 1,386 Gitea instances across seven countries, with a separate dataset of 477 Taiwan-based systems, and 13 confirmed compromises across six countries — Taiwan (4), the United States (4), Canada (2), Argentina (1), Qatar (1) and Sri Lanka (1). On compromised hosts the group deploys a C++ Linux implant called JITTERLY supporting more than 30 post-exploitation commands, including shell execution, file transfer, network tunnelling and internal pivoting. Stolen source repositories are a credential problem as much as an intellectual-property one, which is the same lesson the GitLab flaw above teaches: after the patch, rotate.

Breaches & Incidents

Identity

Microsoft details two campaigns: passkey-themed social engineering and hijacked email infrastructure

Disclosed 13 September. In one, attackers abuse third-party email delivery infrastructure to blast financial-fraud scam messages — borrowed sending reputation, which is what gets such mail past filters. In the other, they use passkey-themed social engineering to breach cloud environments: notable because passkeys are the control organisations are being told to adopt to stop phishing, and the lure works by walking a user through enrolling an attacker-controlled credential rather than by defeating the cryptography. Nothing read this run attributes either campaign to a named group or gives victim counts, and neither is asserted here.

AI abuse

Attackers used Claude to strip secrets out of 1.8 million Android apps

Anthropic has published an account of three operations it disrupted between December 2025 and August 2026 that were abusing its Claude models: the ShinyHunters extortion collective, the Russian espionage group tracked as Midnight Blizzard, and a Chinese-speaking operation it labels GTG-10007. The largest single pipeline mass-downloaded 1.8 million distinct Android APKs from multiple app-store sources, decompiled them and scanned the code with TruffleHog for hardcoded credentials, API keys and tokens. It was run by a French-speaking operator using the aliases MeowSHA, frkoo and blazespider, across a fleet of 10 AWS EC2 workers; nothing read this run states which — if any — of the three named groups that operator belongs to, so no link is asserted here. Across the three groups the reported misuse covers credential harvesting, malware development, reconnaissance and data exfiltration. Anthropic says it suspended the accounts, changed its guardrails, added faster misuse detection and notified authorities, industry partners and victims. The defensive lesson is not about the model: secrets compiled into a shipped mobile binary were always readable — automation only changed how fast 1.8 million of them could be read.

Identity data

IDScan confirms the breach behind 153 million driver’s-license scans

Identity-verification vendor IDScan has confirmed that attackers reached customer data held in its cloud platform, days after a database offered for sale was traced to it. Its 4 September security notice says it learned on or around 1 September that data may have been accessed without authorisation. The trove is reported as 153 million driver’s licences, 10 million ID cards, 3 million international travel cards and 579,000 medical cards, including marijuana dispensary cards; affected fields may include full names and driver’s-licence or other government-issued identification numbers. Brian Krebs verified samples by searching the database for his own record and for others who had consented to the check, and tracked the leak back to IDScan. The FBI has opened an inquiry and multiple lawsuits have already been filed. Scanned identity documents are the one credential class a victim cannot rotate, which is what separates this from a password dump.

Account takeover

HBO Max’s Reddit account was hijacked to run 108 malware ads

The verified u/hbomax account was compromised and used to launch 108 malicious advertisements over about 48 hours, per Hudson Rock and ADAMnetworks. The ads ran ClickFix lures — pages that talk the visitor into pasting a command into Terminal, Run or PowerShell — and led to convincing fake download sites such as hbomaxx[.]us. Payloads seen include MacSync, which takes browser credentials, Firefox profiles, Telegram data, Apple Notes and macOS passwords; an “AMOS helper” persisting under a directory named .com.apple.accountsd; Amatera Stealer loaded into memory on Windows; and fake Ledger, Trezor Suite and Exodus wallet apps built to harvest recovery phrases. Researchers link it to a wider operation they call PasteSwitch. The 108 ads split: 40 pointed at hbomaxx[.]app, 36 at a fake AI and developer site, 15 at a macOS utility page, 11 at a code-editor page and six at a second HBO Max clone — so the campaign was aimed at developers and AI-tool searchers as much as at streaming subscribers. Reddit paused the ads after they were reported. How the account was taken is still unknown, and BleepingComputer says HBO and Warner Bros. Discovery have not responded.

Cloud credentials

Mass scanning of exposed Vite dev servers for AWS and Azure secrets

F5 Labs reports an automated campaign against internet-facing Vite development servers, reading restricted files to lift AWS credentials, Azure tokens, environment variables and infrastructure-as-code secrets. Its honeypots recorded 807 session-grouped attacks and roughly 32,000 raw events in August 2026, against just 1,732 Vite-related file-read events over the preceding three months. The main vehicle is CVE-2026-39364, a file-disclosure flaw published in April 2026 affecting Vite 7.1.0 through 7.3.2 and 8.x before 8.0.5, which bypasses server.fs.deny and returns configuration files over HTTP. Older Vite access-control bypasses were tried too, which suggests a broad exploit library rather than one bug. F5’s advice: update Vite, block port 5173 at the perimeter, and rotate anything that may have been read.

GovernmentConfirmed

Florida DMV confirms DAVID database breach

FLHSMV confirmed on 11 September that its DAVID driver database was accessed using credentials belonging to one Plant City Police Department employee, improperly stored on a personal device. ShinyHunters claims more than 200,000 driver records.

FintechExtortion

Revolut handed customer data to a government impostor

An unauthorised party submitted fraudulent information requests from a legitimate government agency email domain; because the mail carried valid domain authentication, Revolut fulfilled them. Exposed: names, dates of birth, postal and email addresses, phone numbers and copies of passports and driver’s licences, possibly also verification selfies, account statements and transaction histories. Funds were not affected. A threat actor is now demanding payment not to publish more. Revolut has not named the agency or the domain.

Supply chain

Malicious Twitch extension leaked ~31,000 OAuth tokens

“Twitch Enhanced Viewer | JeetBot”, developer HISHIMIRO/jeetbot.cc, was live on both the Chrome Web Store and Firefox Add-ons when Socket published on 11 September — roughly 30,000 Chrome users and 552 on Firefox. It routes Twitch playlist requests through JeetBot proxies and the user’s OAuth token rides along as a URL query parameter, in cleartext, into the proxy’s logs. Those tokens allow account actions without the password or 2FA. For ten hardcoded Russian-language channels it proxies traffic with no token attached at all — it never needed the token to work.

Leak-site claim

Glasfloss listed by Chaos ransomware — 402 GB claimed, and that is all it is

A ransomware-tracking index recorded on 14 September that the air-filtration manufacturer glasfloss.com had been claimed by the Chaos ransomware group, with an estimated attack date of the same day and 402 GB said to be exfiltrated. The listing describes internal documentation across multiple departments, including accounting and finance records, contracts and ESOP paperwork.

This is an extortion-site claim and is published as one. No confirmation from the company, no regulator filing and no independent verification appeared in anything read this run. Leak-site posts are advertising: they routinely inflate volumes, recycle old data and occasionally name victims who were never breached. It is carried here because the claim itself is a fact and the volume is specific — not because the breach is established.

CISA KEV & Federal Deadlines

  • 31 August — two added, and they are today’s real emergency. CVE-2026-82078 (PaperCut NG/MF unsafe reflection, CVSS 9.4) and CVE-2026-81578 (missing authentication, CVSS 8.8). Federal agencies were instructed to remediate by 14 September 2026 (0 days left — due today). Note the window: 31 August to 14 September is two weeks. New The previous edition flagged that as unexplained against the three-week clock of BOD 22-01 and declined to reconcile it. It is not an anomaly. BOD 26-04, issued 10 June 2026, supersedes and revokes BOD 22-01 and replaces its uniform window with a 16-tier remediation matrix keyed to four binary factors — whether the asset is publicly exposed, whether the CVE is in KEV, whether exploitation is automatable, and the post-exploitation technical impact. Sixteen tiers is exactly what four such factors produce. The most dangerous tier must be closed within three calendar days, with mandatory forensic triage; the lowest defers to the next upgrade cycle, and agencies must be operating to the matrix by 7 December 2026. A fourteen-day PaperCut clock is one tier of that matrix — the directive working as written, not a discrepancy. Reads this run differ on the longest fixed window, one saying 14 days and another 60, so no outer bound is asserted here. This page had not carried the PaperCut entries at all until the previous edition.
  • 11 September — one added. CVE-2026-85706 (GitLab path traversal). Remediation due 14 September 2026 (0 days left — due today), with forensic triage required under BOD 26-04.
  • ConnectWise ScreenConnect CVE-2026-84869 was added on Friday with CISA urging agencies to patch within three days as mandated by BOD 26-04 — federal due date 14 September 2026 (0 days left — due today). That three-day window is BOD 26-04’s, not the old three-week BOD 22-01 clock.
  • 9 September — four added, and this run finally has their identifiers. CISA’s 9 September alert names CVE-2025-25249 (Fortinet, heap-based buffer overflow across multiple products), CVE-2026-19490 (Citrix NetScaler authentication bypass), CVE-2026-20079 (Cisco Secure Firewall Management Center and Security Cloud Control authentication bypass) and CVE-2026-87491 (Google Chromium V8 out-of-bounds write). Earlier editions of this page tracked these as an unnamed “Cisco, Citrix and Fortinet trio” due 12 September (overdue by 2 days); that due date is retained from this site’s standing corrections, but note the batch is four, not three — the Chromium entry travels with them. Cisco’s CVE-2026-20079 is separately described as under active exploitation in a vulnerability brief read this run, and Cisco disclosed on 11 September that three distinct threat clusters — tied to both ransomware and state-sponsored activity — exploited Secure FMC flaws to steal credentials and deploy Qilin ransomware. That is the difference between a KEV entry and a hypothetical: the auth bypass is a documented ransomware entry point.
  • 10 September — two added: CVE-2026-67277 and CVE-2026-86060, both in MikroTik RouterOS. New to this page. CISA’s alert page states the additions; no remediation date for either appeared in anything read this run, so none is printed rather than inferred from the batches either side of it.
  • 4 September — one added: CVE-2026-85046, a type-confusion flaw in Google Chromium V8. CISA’s 4 September alert page states the addition; no remediation date for it appeared in anything read this run, so none is printed here.
  • 8 September — four added: CVE-2026-75650 (Adobe Commerce/Magento), CVE-2026-81963 and CVE-2026-85880 (the two Windows zero-days) and CVE-2026-86218 (N-able N-central static code injection). The batch splits: CVE-2026-75650 was due 11 September (overdue by 3 days) on a three-day window, while the other three are due 22 September (8 days left). Dates per this site’s standing corrections file, which pinned the split from the CISA alert; nothing read this run restated them.
  • 2 September — seven added: Sangoma Switchvox (CVE-2026-9586), Kludex Starlette (CVE-2026-48710), Kestra OSS (CVE-2026-49869), BerriAI LiteLLM (CVE-2026-59822), JFrog Artifactory (CVE-2026-82329) and two SonicWall SMA1000 flaws (CVE-2026-83548, CVE-2026-83549). CISA’s alert said agencies were “recommended to apply patches for most of these by 5 September 2026” — the hedge is the source’s (overdue by 9 days).
