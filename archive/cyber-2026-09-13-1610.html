Top Story

NewActively exploitedCVSS 10.0

Sandworm and Qilin are both inside Cisco’s firewall manager

Cisco Talos disclosed on 9 September that it is tracking real-world exploitation of two flaws in Cisco Secure Firewall Management Center (FMC). CVE-2026-20079 carries a maximum CVSS 10.0: an unauthenticated, remote attacker can bypass authentication and execute scripts as root on the underlying operating system. CVE-2026-20316 (CVSS 5.3) lets a remote attacker log in with a low-privileged account, and is chained with other FMC flaws to escalate.

Talos identifies three separate clusters of post-compromise activity. UAT-12197 exploits CVE-2026-20079 to plant JSP web shells and a Java archive (JAR)-based command executor in Tomcat webroot directories, then queries internal databases to harvest user authentication data and credentials. UAT-11823 is linked to the Russian state group Sandworm (GRU Unit 74455) and deploys Cyclops Blink, a modular Linux malware family previously attributed to the same group. UAT-11988 is associated with the Qilin ransomware operation, and leans on CVE-2026-20316 alongside 20079 for living-off-the-land reconnaissance and credential theft before deploying ransomware.

A firewall-management appliance is a worst-case foothold: it holds the policy for everything behind it and the credentials used to administer it. CVE-2026-20079 sat in the KEV set whose federal deadline was 12 September — that deadline is now past.

Patch Priority

Do this first — deadline already passed
Cisco Secure Firewall Management Center — CVE-2026-20079 (CVSS 10.0). Unauthenticated bypass to root, confirmed exploited by a Russian state group and a ransomware crew. Its federal remediation deadline was 12 September 2026, which is one day overdue as of this edition. Patch, then treat every unpatched FMC as presumed-compromised and hunt for JSP files and stray JARs in Tomcat webroots rather than assuming patching is sufficient. Immediately behind it: GitLab CVE-2026-85706, also CVSS 10.0, due tomorrow, 14 September.

Threat Actor Spotlight

NewState-sponsored

Sandworm — tracked by Talos in this campaign as UAT-11823

Attributed to GRU Unit 74455, Sandworm is the cluster deploying Cyclops Blink onto exploited Cisco FMC appliances. Cyclops Blink is a modular Linux malware family already attributed to Sandworm in prior reporting, and its reappearance on a firewall-management platform continues the group’s pattern of living on network edge devices rather than endpoints. Talos places it alongside, but distinct from, the credential-harvesting cluster UAT-12197 and the Qilin-linked UAT-11988 — three groups, one bug, no shared tooling described.

Breaches & Incidents

Zero-dayOverdue

StyleSmuggler: Magento and Adobe Commerce backdoored

CVE-2026-75650 (CVSS 10.0), codenamed StyleSmuggler by Sansec, abuses Magento’s template system through PHP code injection to generate a “Payment Transaction Failed Reminder” email, executing code in the process. Every version from 2.4.4 up to and including 2.4.9 is affected. Attackers deployed a Rust-based Linux backdoor disguised as [kworker/u:8:0] and, in separate attacks, a PHP web shell. Sansec detected the first confirmed exploitation on 4 September at 22:20 UTC, disclosed it on 5 September, and Adobe issued the CVE, bulletin and VULN-39341 hotfix on 7 September.

NewVendor patch

Broadcom patches a critical VMware desktop flaw

Broadcom released security updates for critical flaws in VMware Workstation and Fusion, including CVE-2026-59346, an integer-overflow vulnerability that can result in arbitrary code execution. No CVSS score and no exploitation evidence were stated in the reporting returned this run, so neither is asserted here.

NewExploited

SonicWall SMA1000 pair exploited in the wild

Rapid7 flags CVE-2026-83548 and CVE-2026-83549, critical vulnerabilities in SonicWall SMA1000, as exploited in the wild. The advisory returned this run states no CVSS figures, so none are printed; the pairing and the exploitation status are what the source supports.

NewPatch fallout

September’s Windows update breaks Always On VPN

Microsoft’s September 2026 security update KB5124008 caused issues for Windows 11 enterprise clients using Always On VPN after Patch Tuesday. This is an availability problem rather than a compromise, but it is the kind of side effect that delays the very patch cycle the deadlines above depend on.

Carried

JetBrains’ own Cadence environment breached via TeamCity

Attackers exploited a critical TeamCity vulnerability to breach JetBrains’ Cadence environment and extract AWS credentials. Restated at search level this run; the full timeline (intrusion 8–24 August, discovered 23 August, a full 2024 Cadence server backup and multiple AWS IAM secrets taken, via CVE-2026-63077) is carried from this site’s standing corrections file rather than re-fetched, and is labelled as carried.
