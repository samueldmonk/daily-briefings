Top Story

PaperCut's emergency patch was bypassed. The second one shipped a day later.

PaperCut published an urgent advisory on August 27 saying it was investigating active exploitation of a flaw in PaperCut NG and PaperCut MF. On August 28 it assigned two identifiers to what turned out to be an exploit chain: CVE-2026-81578, a high-severity authentication bypass rated 8.8 in the web management interface, where “unauthenticated remote requests targeting administrative functions can trigger backend actions prior to the completion of access validation checks”; and CVE-2026-82078, a critical unsafe dynamic class-loading flaw rated 9.4 in PaperCut's database connection utilities, which loads driver classes from a configurable name without validating it against an allowlist.

Chained, they are pre-authentication remote code execution. In watchTowr head of threat intelligence Jake Knott's description: CVE-2026-81578 gets you past authentication, and from there you edit a configuration file to exploit CVE-2026-82078 and gain RCE.

Emergency patches now exist for NG/MF versions 24, 25 and 26 across Windows, Linux and macOS — and the current builds are Emergency Patch Release 2, published August 28 after PaperCut worked with watchTowr and Huntress researchers to close bypasses of the earlier patches. Administrators who applied the first patch are not finished.

The worst of it, first published in the 9:15 edition and re-verified against two independent reports this run. watchTowr reports it found multiple patch bypasses plus an additional authentication bypass; one of those bypasses was closed in Emergency Patch Release 2, but the researchers state that new patch bypasses affecting the latest, fully patched version have been identified. Read that precisely: applying the current patch is necessary and, on this reporting, not provably sufficient — which is why PaperCut's own advice to take the application server off the internet still matters more than the version number.

Exploitation is also no longer abstract. Huntress reports detecting exploitation of the chain in two customer environments as of August 27; in one, the attacker ran base64-encoded whoami and ver commands to identify the account context and the operating system version. That is manual reconnaissance immediately after access — a useful thing to hunt for in your own command-line logging.

Still not stated by any source seen this run, and therefore not printed: the threat actor, the number of victims, whether ransomware is involved, or how many servers are exposed.

Patch Priority

CVE-2026-8452 — Citrix NetScaler ADC and Gateway — federal deadline expires TODAY

CISA added this to the Known Exploited Vulnerabilities catalog on August 26 with a federal remediation date of Saturday, August 29. That is today: the countdown below reads 0 days left, and it does not get another edition. It is a pre-authentication heap memory overflow in the code that parses SAML single-sign-on messages in the appliance's AAA service, carrying a CVSS v4.0 base score of 8.8. Defenders have observed web shells and discovery activity on compromised appliances. If you run NetScaler with AAA or Gateway exposed, this is the item on this page most likely to be already overdue when you read it.

The exploitation is quantified — carried from the 8:46 edition, where it was first sourced. Telemetry cited by CISA-tracking researchers records 36 exploitation attempts over the past 12 days from 12 unique attacker IP addresses across Switzerland, Germany, Hong Kong, Japan, the Netherlands, Russia, Singapore, Türkiye, the United States and Vietnam. The observed post-exploitation behaviour is specific enough to hunt for: attackers dropped web shells named x.php and z.php and ran discovery commands including id and echo. If you cannot patch today, look for those filenames first.

A second deadline expires alongside it. CVE-2019-1068, a remote code execution flaw in Microsoft SQL Server that lets an attacker execute code in the context of the SQL Server Database Engine service account, was added to KEV in the same August 26 batch and carries the same August 29 due date. It ranks second here only because there is currently no public information on how it is being exploited in the wild — which is a reason to patch it, not a reason to deprioritise it.

A build-number discrepancy, recorded rather than resolved. The source seen this run gives the fixed builds as 14.1-73.32 and later, or 13.1-63.21 and later (with corresponding FIPS and NDcPP builds). The previous edition carried 14.1-72.61 / 13.1-63.18 / 13.1-37.272 from a different source. Both are printed; neither is discarded. Take the higher build in each train — if the newer numbers are right, the older ones leave you exposed; if the older ones were sufficient, installing the newer build costs nothing. Verify against Citrix advisory CTX696604 before you act on either.
Vendor framing vs researcher finding, both kept. Citrix disclosed and patched the issue on June 30, 2026, describing it only as a memory overflow that could cause a denial-of-service condition. In mid-August, watchTowr Labs demonstrated the same flaw driven to unauthenticated remote code execution. This page prints both characterisations and does not pick one.

Threat Actor Spotlight

CarriedAgentic AIChina-nexus

UAT-10147 — and the SPECTRE implant

First published in the 8:46 edition and carried unchanged. Cisco Talos has documented a Chinese-speaking cybercrime group tracked as UAT-10147, active since early 2026, that targets internet-facing Windows and Linux web servers for data theft and SEO fraud. What sets it apart is that it has wired AI-driven tooling into exploitation, reconnaissance, payload generation, validation and persistence. Talos recovered AI-generated operational playbooks from actor infrastructure — including a nine-section ASP.NET ViewState exploitation guide documenting a real intrusion in granular detail, down to hostnames, IP addresses and the MachineKey values needed to forge a valid ViewState payload — alongside a target list of roughly 170,000 URLs. Tooling observed: Metasploit, ysoserial, PentestGPT, DeepAudit and multiple privilege-escalation exploits. Its most capable payload is SPECTRE, a custom C backdoor for Windows and Linux; the Windows build supports 45 commands covering screenshots, credential theft, keylogging, token impersonation, process injection, in-memory .NET execution and privilege escalation, with Linux rootkit and BYOVD capabilities reported. This is the group behind four of the six CVEs CISA added on August 26 — the two Red Hat flaws, the Linux kernel write and the Ajax.NET deserialization bug.

CareCloud — 3,756,469 individuals, filed this month

The health-IT vendor has confirmed to the U.S. Department of Health and Human Services in an August 2026 filing that its March 2026 intrusion affected 3,756,469 people. An unauthorised third party had access to one of CareCloud’s Amazon Web Services environments between March 10 and March 16; that environment hosted one of the company’s six electronic health record systems, and the intruder claimed to have exfiltrated databases stored in it. Reported categories: names, addresses, Social Security numbers, driver’s licence numbers, dates of birth, health insurance information and medical records, with full payment card information for a very limited subset. Identity-theft protection and credit monitoring are offered through IDX. No ransomware group or extortion gang has publicly claimed the attack, and none is named here. ⚠ The victim count grew rather than changed: the same outlet headlined “over 350,000” earlier and “3.7 million” later — that is a filing being amended upward over time, not two sources contradicting each other, and the page prints the current filed figure with its history rather than the larger number alone.

CarriedAviation8.7M

Manchester Airports Group — 8.7 million customers

MAG, which operates Manchester, London Stansted and East Midlands airports, says an unauthorised third party accessed customer data tied to car park, lounge and Fast Track bookings and in-airport Wi-Fi sign-ups. Accessed: email addresses, phone numbers, vehicle registrations and postcodes. Explicitly not held by MAG or the affected system: bank or payment details. Flights, airport operations and parking continue normally; the online Manage My Booking service is temporarily suspended and existing reservations remain valid.

Updated · 9:40 AMMedical devices

Boston Scientific — a supply chain stopped

The company identified a cybersecurity incident affecting certain IT systems on August 25, causing a network outage and an ongoing global disruption to operations. Among the systems hit are those used to process and ship customer orders — the practical effect reported is that pacemaker and cardiac stent shipments to hospitals have halted. Incident response is active with third-party experts; the company does not know when full system access will be restored. Piper Sandler analysts suggest a return to shipping all products in under three weeks. New this run: thousands of employees in Ireland, where the company runs three manufacturing and research sites, were told to work from home on August 26 after network communications were severed; analysts are modelling a hit of up to 700 basis points to third-quarter revenue, and the shares fell as much as 6% after disclosure. A spokesperson declined to say whether ransomware was involved and said a full-restoration timeline is still unknown. No actor, ransom demand or data-theft claim is stated; none printed.

These windows are assigned per-CVE under BOD 26-04, which prioritises security updates based on risk. They are not computed by this page and they do not follow a fixed interval: the Aug 26 batch splits 3 days for two CVEs and 14 days for the other four from the same add date, and the Aug 27 batch splits 3 and 14 the same way. The older BOD 22-01 “three weeks from the add date” heuristic is superseded and is not used here. Countdowns above are measured from Saturday, August 29, 2026.
What changed since the last edition. The Aug 26 batch is now fully enumerated — the previous edition carried only the Citrix entry from it and described the Aug 27 batch as “three CVEs”. Six were added on Aug 26, and a second deadline expiring today (CVE-2019-1068) was previously unrecorded on this page. Four of those six are attributed by Cisco Talos to UAT-10147, which is why the spotlight above and this section describe the same operation. The Oracle item (CVE-2026-21962), overdue as of Aug 27, was again not restated by any source seen this run and is again not carried.
Context from CISA's own review, published alongside the batch. Analysing CVE records from 2024 and 2025, the agency found injection weaknesses the most dominant category — 7,701 CVEs in 2024 and 21,019 in 2025 — and reported that memory safety and improper input validation weaknesses appear disproportionately in KEV entries compared with the full CVE population. CISA's framing: attackers are exploiting simple, known flaws that persist in exposed assets, and AI is being used to automate that exploitation. The four aged CVEs above — two from 2015 — are the argument made in list form.
  • Context sourced this run — the industry has written down its own threat model, and the signatory count is reported four different ways. An open letter led by OpenAI calls for a coordinated global surge in cyber defence as AI makes attacks more widespread and sophisticated. ⚠ The number of signatories is not agreed across the sources fetched this run — four different counts, none of which this page adopts: CNBC counts 116 companies and entities, SecurityWeek says nearly 130, one trade outlet says more than 130, and CyberScoop says 100-plus. The letter states that “in the coming months, AI-enabled cyber attacks will become far more widespread and sophisticated as models around the world become increasingly capable,” and names hospitals, water treatment plants and internet infrastructure as at increasing risk. Its asks: treat cyber defence as an immediate leadership priority, fix the most dangerous vulnerabilities, and raise the bar on what is bought, built and deployed. The first of those asks is the section above this one — two of the deadlines on this board expire today.
