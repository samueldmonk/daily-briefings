Top Story

Adobe patches StyleSmuggler — but a patched store is not a clean store

Adobe published APSB26-146 on 7 September for CVE-2026-75650, rated CVSS 10.0 and acknowledged by the vendor as exploited in the wild. The flaw is an unauthenticated remote code execution reached by abusing Magento's template system: PHP is injected through the path that generates a “Payment Transaction Failed Reminder” email, and executes when that mail is built. Sansec, the Dutch forensics firm that found and named it, dates the first exploitation to 4 September and reproduced the full unauthenticated chain against clean installs.

Every version from 2.4.4 up to and including 2.4.9 is affected. Fixed patch levels read this run are 2.4.4-p18, 2.4.5-p17, 2.4.6-p15, 2.4.7-p10, 2.4.8-p5 and 2.4.9; Adobe's own remedy is a hotfix archive, VULN-39341-composer-patches.zip, applied as a composer patch rather than shipped as a release. A third party, Disrex, has published a mitigation package for the same flaw on GitHub and Packagist for operators who cannot take the vendor archive directly.

The operational point is not the patch. Stores were being compromised for roughly three days before a hotfix existed, and the payloads reported are a Rust-based Linux backdoor beaconing to an external server and a PHP dropper that writes an arbitrary-PHP web shell — neither of which a patch removes. The guidance read this run is explicit that patching closes the hole but does not clean a store that was already hit, so a compromise assessment is the second half of this job, not an optional extra.

One conflict, printed rather than resolved. A breach-tracker round-up read this run attributes StyleSmuggler to CVE-2026-32475 at CVSS 9.8 and describes it as an arbitrary file upload in a form-submission handler. That contradicts the identifier, the score and the mechanism given by Adobe's own bulletin and by Sansec, who discovered it. This page follows the vendor advisory and the discoverer; the round-up figure is recorded here so the disagreement is visible, and is not used anywhere else on this page.

Patch Priority

Do this first

CVE-2026-75650 — Adobe Commerce / Magento Open Source, all versions 2.4.4 through 2.4.9. Maximum severity, unauthenticated, no user interaction, and confirmed exploited in the wild by the vendor. Apply the APSB26-146 hotfix or move to the fixed patch level for your exact release, then assume the store may already be compromised and hunt for the Rust backdoor and PHP web shell described above.

No federal remediation date for CVE-2026-75650 was confirmed this run — it does not appear in the 2 or 4 September KEV additions this page lists, and no claim is made here about the catalogue as a whole. The nearest open federal deadline this page does carry is the 14 September date on the PaperCut pair, 6 days out, which is the same date and the same count used in the KEV section below.

Threat Actor Spotlight

NewExtortionSaaS

PREY-0058 — the help desk is the vulnerability

Disclosed 7 September: a data-theft and extortion cluster tracked by Arctic Wolf as PREY-0058, sharing significant tradecraft with UNC6671, a data-extortion group identified by Google Threat Intelligence. The extortion side has surfaced under several names — BlackFile, Pink, Helix, Cinder and Redact. The entry point is a phone call: IT help-desk vishing that walks a target into an operator-controlled adversary-in-the-middle Microsoft 365 login flow, harvesting the credential and the MFA approval to capture an authenticated session token. Those tokens are then replayed from residential-proxy infrastructure such as NodeMaven, from addresses matching the victim's own geography and ASN, which is what defeats the usual impossible-travel signal. Targeting skews to directors, vice presidents and other executive staff; the final stage is bulk collection out of SharePoint, OneDrive, Exchange and third-party SaaS including Box. No CVE is involved anywhere in this chain.

Breaches & Incidents

ExpandedExploitedEducation

PaperCut servers worked against schools in three countries

Attackers are chaining CVE-2026-81578 (authentication bypass) and CVE-2026-82078 (remote code execution) against internet-facing PaperCut NG/MF servers to steal credentials, run commands and create privileged accounts. Victims run from K-12 schools to major universities; most confirmed cases are in the United States, with others in Denmark and Ireland. Reported post-exploitation activity includes Windows registry-hive collection tooling, Metasploit/Meterpreter Java payloads, and host, user and process reconnaissance. PaperCut has issued emergency patches. Defensive advice read this run: take these servers off the public internet, and alert on cmd.exe, powershell.exe or other interpreters spawned by pc-app.exe. Tagged Expanded, not New: the CVE pair and the 14 September date were both on this page's previous edition — the campaign detail, the countries and the post-exploitation tooling are what is added here.

NewRansomware

Lightcast hit; activity attributed to “direwolf”

Lightcast, a US-based provider of human-resources software, was named this month in a ransomware incident attributed to the direwolf threat actor, with reported impact to operations and data availability in the United States. No ransom figure, victim count or data volume was stated in anything read this run, so none is printed.

CarriedExtortion claim

INC Ransom claims 5.7 TB from a state attorney general

INC Ransom has claimed in September that it took 5.7 terabytes of data in the Pennsylvania Office of Attorney General ransomware attack of August 2025, with exposed files said to potentially contain names, Social Security numbers and medical information. This is the actor's own claim as reported in a breach tracker; nothing read this run is a confirmation by the office itself. It carried a New tag on this page's previous edition and has lost it here, because it was in that edition — the claim has not changed, only its age.

CarriedNo CVE

Blockstream's Liquid bridge still frozen after a ~$320m drain

Carried from this desk's earlier verified entry rather than re-sourced this run: self-described white-hat actors moved about 4,000 BTC — roughly $320 million, close to 95% of the reserves backing the Liquid Network sidechain — out of the federation wallet on 6 September, and Blockstream disabled the bridge nodes, pausing the two-way peg. About 3,400 BTC was returned. There is no CVE, no CVSS, no affected version and no vendor patch attached to it, which is why it appears in no table on this page and carries no deadline. The white-hat label is the actors' own on-chain message.
