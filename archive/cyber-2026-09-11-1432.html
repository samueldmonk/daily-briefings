Top Story

Cisco Talos Confirms Two Secure FMC Flaws Under Attack — Sandworm and Qilin Among Three Intrusion Clusters

“Cisco Talos is actively tracking the exploitation of two vulnerabilities in Cisco’s Secure Firewall Management Center (FMC) Software,” the company’s researchers confirmed on Wednesday. The pair are CVE-2026-20079 and CVE-2026-20316, both in the FMC web interface — the console used to centrally manage fleets of Cisco Secure Firewall devices.

CVE-2026-20079 carries a CVSS score of 10.0. It stems from an improper system process created at boot time, and lets a remote, unauthenticated attacker execute scripts and commands as root simply by sending specially crafted HTTP requests. It was found internally by Cisco’s Brandon Sakai and fixed in early March 2026. CVE-2026-20316, reported by Jimi Sebree of Horizon3.ai and disclosed with a fix on July 29, is a set of static, hard-coded credentials for a low-privileged account that lets unauthenticated attackers simply log in.

Cisco updated its advisory to say it became aware of active exploitation of CVE-2026-20079 in August 2026, and Talos has now detailed three post-compromise clusters — tracked as UAT-12197, UAT-11823 and UAT-11988. The first drops a web shell in the CSM Tomcat webroot and then a malicious JAR file used to harvest authentication data. The second, believed to be the work of Russian state-sponsored group Sandworm, replaces license.tmp with a malicious copy to open a reverse shell, harvests the configuration files of every managed firewall, and installs an implant capable of credential theft, command execution, packet sniffing and network scanning. The third, suspected to be a Qilin ransomware operator, logs in with the static credentials, runs network and endpoint reconnaissance, steals credentials, deploys AV killers and delivers the ransomware.

Talos published indicators of compromise and urged customers to apply the released hotfixes now rather than wait: a comprehensive hardening release is scheduled for the week of September 16. Where patching cannot happen immediately, Cisco’s alternative is to make the FMC management interface unreachable from the internet.

Patch Priority

Patch Priority — CVE-2026-20079, Cisco Secure Firewall Management Center (CVSS 10.0)

If you run an on-prem FMC, this is today’s job. CISA added it to the Known Exploited Vulnerabilities catalog on Sept. 9 and set an FCEB remediation deadline of September 12, 2026 — 1 day left. Exploitation is unauthenticated, gives root, and is already being used by a nation-state group and a ransomware operator. Apply Cisco’s hotfix now; if you cannot, pull the management interface off the internet and hunt against Talos’s IOCs before you do anything else.

Sandworm — the second FMC intrusion cluster

Per Cisco Talos, the Russian state-sponsored group gains access through one of the two FMC flaws, then swaps license.tmp for a malicious copy to establish a reverse shell to its command-and-control server. From there it harvests the configuration files of every Cisco firewall the appliance manages, and installs an implant that can collect credentials, execute commands and files, sniff packets and scan the network. The prize is not one box — it is the ruleset, the topology and the credentials for an entire perimeter.

Trezor: 347,000 users phished after a Brevo compromise

Attackers compromised the Brevo marketing platform and used it to send phishing mail to customers of Trezor, BitBox and CoinTracking. Trezor says the campaign targeted 347,000 email addresses and that 2,500 users clicked the embedded malicious link. Roughly 120 Brevo accounts were abused to ship fake security alerts; Trezor says it got the phishing domain taken down within twenty minutes.

NewLitigation

IDScan sued over an alleged 153-million-licence breach

Multiple lawsuits have been filed against identity-verification firm IDScan after attackers allegedly breached the service and offered its data for sale. A dark-web identity-theft platform called Nexus advertised more than 153 million U.S. and Canadian driver’s-licence scans, 10 million ID cards, 3 million travel documents and 579,000 medical cards. The FBI’s New Orleans field office has confirmed it is investigating.

CISA: the WatchGuard Firebox bug is now a ransomware play

On Sept. 9 CISA confirmed that CVE-2025-14733 — an out-of-bounds write in WatchGuard Firebox that has been in the KEV catalog since December — is being used in ransomware campaigns. It allows unauthenticated remote code execution in low-complexity attacks against Fireware OS 11.x (incl. 11.12.4_Update1), 12.x (incl. 12.11.5) and 2025.1 through 2025.1.3. Shadowserver counted more than 115,000 exposed unpatched boxes in December; nearly 9,000 remain unsecured nine months on. WatchGuard says only IKEv2 VPN configurations are exploitable — but warns a device may still be compromised even after deleting the vulnerable config, if a branch-office VPN to a static gateway peer is still in place.

NewOperational

September Windows Server updates are breaking Remote Desktop

Administrators report that this month’s cumulative updates — KB5122876 (Server 2019), KB5122882 (Server 2022) and KB5122871 (Server 2025) — break Remote Desktop Services. RDS works initially, then fails after a few hours or after users log out, blocking new connections and hanging existing sessions; some hosts need a hard reset. One administrator’s analysis traces it to a mutual block between the Remote Desktop service and the Local Session Manager. Microsoft has not confirmed a cause or shipped a fix; rolling back restores RDS but removes the security fixes.

Campaign

PivotC2: a Node.js RAT riding the FortiOS flaw

SOCRadar reports a campaign weaponising CVE-2025-25249 to deliver PivotC2, a Node.js remote-access trojan. A shell script drops an exploit binary against a vulnerable FortiGate, establishes a reverse shell and pulls a second-stage JavaScript payload. PivotC2 holds a persistent outbound TLS connection and supports interactive shells, file transfer, SOCKS5/HTTP proxy tunnelling, port forwarding, CIDR scanning and FortiGate-specific config harvesting and credential decryption. More than 3,000 IP addresses were targeted and 178 devices infected, most in the U.S.; the operator is assessed to be a financially motivated Russian speaker, with exploitation dating back to July 2026.
