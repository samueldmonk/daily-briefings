Top Story

Intrusion tradecraft · Sysdig

A human attacker reached an SSH bastion eight seconds after exploiting a Marimo notebook — without an AI agent

Cloud security company Sysdig has published findings on an intrusion in which a skilled human operator pivoted from a vulnerable Marimo notebook to an SSH bastion host in eight seconds, using a custom Python toolkit the Sysdig Threat Research Team says the attacker “wrote and debugged by hand” with no AI agent in the loop.

The significance is the comparison Sysdig itself draws. “Eight seconds is the kind of speed we expect to see in AI-assisted attacks,” the team wrote — and it adds that this operator walked straight past a trap that every agentic threat actor it has profiled against the same Marimo flaw fell into. Its conclusion is that skilled human attackers not only move at machine speed, they often evade defender detections better than agents do.

That cuts directly against the framing this page carried this morning, when GreyNoise’s “Agents Gone Wild” report on hundreds of AI agents driving the PaperCut campaign was the lead. Both findings are published this week and neither cancels the other: speed is no longer a reliable signal of automation, in either direction. Sysdig’s report is dated 15 September 2026.

Patch Priority

Do this first

Patch Cisco Secure Email Gateway (AsyncOS) against CVE-2026-76461 — CVSS 9.8, exploited in the wild, federal KEV deadline 17 September (2 days left).

An unauthenticated remote attacker sends a crafted email carrying malicious SQL and ends up executing arbitrary OS commands as root. Physical and virtual appliances are affected regardless of configuration; Cisco states that Secure Email and Web Manager and Secure Web Appliance are not affected. Cisco PSIRT published the advisory on Monday and has not attributed the attacks. It has released indicators of compromise while noting that an attacker with root can remove them — so for virtual appliances its guidance is a rebuild plus full credential and key rotation, not a patch alone.

Threat Actor Spotlight

EspionageChina-nexus
Red Heron · Acronis TRU

Red Heron turned a fresh Gitea RCE into 13 confirmed compromises across six countries

A suspected Chinese threat actor tracked as Red Heron moved on a recently disclosed remote-code-execution flaw in Gitea fast enough to compromise internet-facing instances at scale. Acronis Threat Research Unit says it scanned 1,386 Gitea instances across seven countries and kept a separate dataset of 477 Taiwan-based systems. Confirmed compromises: Taiwan (4), the U.S. (4), Canada (2), Argentina (1), Qatar (1) and Sri Lanka (1). The activity ran from source-code theft to persistent access, credential collection and lateral movement, including root-level access to a three-node Proxmox cluster. Acronis reports the actor used Simplified Chinese labels to classify targets spanning defence, election, energy, aerospace, telecommunications, government, public safety and research.

Breaches & Incidents

Volexity · UTA0560

A Chrome–Windows zero-day chain delivered the GRIMWEDGE backdoor to NGOs

Volexity attributes a spear-phishing campaign against multiple non-governmental organisations on 1 September 2026 to a Chinese threat cluster it tracks as UTA0560. The emails linked to the website of a U.S.-based university and abused a reflected cross-site scripting flaw there to redirect recipients to attacker infrastructure hosting a multi-stage exploit chain. The chain — previously highlighted by Proofpoint — uses three flaws: two in Google Chrome and one in Windows Advanced Local Procedure Call, and ends in a JavaScript backdoor called GRIMWEDGE.

NewMalware
Lumen Black Lotus Labs

BambooToken uses MQTT as its command channel and sideloads through security-token software

A previously undocumented multi-platform malware family codenamed BambooToken controls Windows and Linux systems over the MQTT messaging protocol. Lumen Black Lotus Labs found it on VirusTotal in early 2026 and assesses it has been active since at least February 2023, in attacks on organisations across Asia and South America, with activity detected as recently as July 2026. The actor sideloads agents using Tendyron’s “OnKey” software — Tendyron makes hardware tokens used in high-security settings to verify identities for workstation access.

NewShared hosting
cPanel advisory, 14 September

One hosting account could reach root on a whole shared LiteSpeed server

cPanel warned in an advisory published 14 September that a critical flaw in LiteSpeed Web Server Enterprise could let a low-privilege website user gain root access on a shared-hosting machine — where many customers’ sites run on one server, so an attacker with a single hosting account could reach or alter other sites and the server itself. The flaw can bypass CageFS, the CloudLinux tool that gives each account a restricted view of the file system. It affects versions before 6.3.7; LiteSpeed published 6.3.7 on 11 September. Neither cPanel’s advisory nor LiteSpeed’s release notes describe how it works.

Telecom
Hunt.io · 3BB, Thailand

An attacker ran a hidden MeshCentral backdoor inside one of Thailand’s largest broadband providers

Threat intelligence firm Hunt.io says an attacker was operating inside the network of 3BB and keeping remote control of internal machines with MeshCentral, a legitimate free remote-management tool configured as a hidden backdoor reporting to an attacker-controlled server. Hunt.io found it by examining a server the attacker left exposed on the internet, captured on 3 June 2026 while the operation was still live, which held the attacker’s tools and a list of machines already under their control. One recovered file showed the attacker taking full root control of an internal server; the tools had been run from a computer inside 3BB’s own network.

Hardware
DDRop · disclosed 14 September

A sub-$200 interposer breaks Intel TDX, Intel Scalable SGX and AMD SEV-SNP

Researchers disclosed DDRop, a hardware attack that defeats the memory protection behind confidential computing by silently dropping writes to a server’s memory, so the processor keeps reading old encrypted data as if it were current. It needs an attacker who already controls the server’s software and can briefly reach the machine to insert a small circuit board — an interposer costing under $200 — between the processor and a memory module. These designs omit a guarantee called freshness in order to cover the large amount of memory a cloud server uses, which is the gap DDRop exploits.

A correction to this page’s own earlier editions today. The 10:04, 10:56 and 11:46 runs carried a “9 September batch of four” (Fortinet CVE-2025-25249, Citrix NetScaler CVE-2026-19490, Chromium V8 CVE-2026-87491, Cisco FMC CVE-2026-20079) under a 12 September deadline. CISA’s own alert listing returned this run shows alerts dated 2, 8, 10 and 14 September and no 9 September alert at all, with the four-CVE alert carrying the Adobe/Windows/N-able members above. The 9 September enumeration is therefore not asserted this run; it is not retired either, because cisa.gov again returned an empty body on direct fetch and the catalog itself has still not been read.
BOD 22-01 is revoked. Deadlines are no longer three weeks from the add date. BOD 26-04, “Prioritizing Security Updates Based on Risk” (10 June 2026), replaced the uniform window with a 16-tier matrix keyed to public exposure, KEV membership and whether exploitation can be fully automated; the most dangerous tier must be remediated within three days, with mandatory forensic triage. Agencies must be operating to these timelines by 7 December 2026. That is why three-day windows and same-week deadlines appear above and are correct. Note also that KEV entry requires evidence of exploitation, so a severe flaw with no confirmed exploitation carries no federal deadline at all.
