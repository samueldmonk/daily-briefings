Top Story

Shai-Hulud rides again: keyv-linked npm worm poisons 2,234 package versions across twelve organizations — and plants Claude Code and VS Code hooks

A credential-stealing npm worm that first appeared in keyv@6.0.0 on August 4 spread beyond the Keyv and Cacheable namespaces into hundreds of packages across multiple organizations. SafeDep's updated registry-backed count now stands at 2,234 poisoned versions across 444 package names spanning twelve unrelated organizations — among them @ornikar, @deliveroo, @servicetitan, @qlik and Picsart — all republished between 09:35 and 13:18 UTC on August 4 (SafeDep, direct fetch this edition). Four of the core libraries — keyv, flat-cache, file-entry-cache and cacheable-request — see a combined 1,877 million monthly downloads, and flat-cache and file-entry-cache ship inside ESLint, so the reach extends to projects that never installed keyv directly. Aikido places the campaign in the Shai-Hulud malware family, and researchers counted 546 public GitHub repositories created August 4 with the description "Shai-Hulud: Here We Go Again" as likely exfiltration or staging artifacts.

The malicious releases use a preinstall script to run a compiled credential-stealing bundle inside developer and CI environments — harvesting GitHub, npm, cloud, Vault, Kubernetes, database and private-key material, reading GitHub Actions runner memory, then using any available npm publishing access to poison more packages. The poisoned Keyv release even carried valid OIDC/SLSA provenance because it passed through the project's legitimate GitHub Actions release workflow. A second execution path lurks in the repository itself: Claude Code and VS Code hook files that can run the payload once a user trusts the workspace — both editors gate this behind workspace trust, but the files were still on main at reporting time (The Hacker News/SafeDep/Socket).

Response order matters: SafeDep advises removing the malware's credential-revocation watcher before rotating tokens — revocation is the watcher's trigger, and rotating first can run an attacker-supplied local handler. The poisoned keyv and cacheable releases have been unpublished, but "latest" still resolved to a malicious version for most other affected names at SafeDep's update, so upgrading alone may preserve exposure — check lockfiles and resolved versions against the affected list, and treat any machine that executed an affected version as credential-exposed (Socket). npm 12 blocks unapproved lifecycle scripts by default; earlier clients remain exposed.

Patch Priority

Most urgent action today

Upgrade N-able N-central to 2026.3.1.7 — federal deadline is tomorrow, Thursday Aug 6 (1 day left)

CVE-2026-18577 (CVSS 8.2, actively exploited, KEV-listed Aug 3) affects all N-central builds prior to 2026.3.1.7. It is a bypass of a prior fix, so systems patched against CVE-2026-18556 are still vulnerable — and CISA has now KEV-listed both flaws, signaling active exploitation of each (The Hacker News). Hosted environments are upgraded by the vendor; on-premise deployments need manual remediation (Rapid7).

Right behind it: the three flaws CISA added this week — Langflow CVE-2026-9198 (CVSS 9.8, unauthenticated RCE on default deployments, fixed in 1.10.1), Apache Tomcat CVE-2026-34486 and N-central CVE-2026-18556 — carry a federal fix-by date of Friday, August 7 (The Hacker News/CISA). Then hunt, don't just patch: review admin accounts, Take Control session logs, newly created Windows services and outbound Cloudflare Tunnel connections (GBHackers).

Threat Actor Spotlight

knaithe / KnYuan — the operator who let DeepSeek pick the targets

Palo Alto Networks Unit 42 attributes the exploitation of the newly KEV-listed Apache Tomcat flaw (CVE-2026-34486) to an AI-enabled autonomous hacking campaign run by a Chinese-speaking threat actor operating as knaithe and KnYuan, based in Zhuhai, China. The actor used DeepSeek, via the Hermes Agent framework, as an offensive operator against internet-exposed devices — attempting to exploit over 460 targets with a mix of autonomous and manual techniques. When an initial Langflow exploit (CVE-2026-33017) failed against a hardened environment, the agent conducted autonomous research to find higher-value alternatives, including flaws in n8n. Unit 42's striking detail: the actor let DeepSeek narrow its own targeting scope, likely to conserve compute — a process that "executed hundreds of hours of manual targeting analysis in mere minutes." The same adversary runs manual operations against known flaws in Citrix NetScaler (CVE-2026-3055), Marimo (CVE-2026-39987), Tomcat and IKE VPN endpoints (The Hacker News/Unit 42).

Breaches & Incidents

NewCrypto theft

Coldcard drain keeps growing: ~$70M in 41 minutes is now ~$89M — and counting

The July 30 sweep that drained 1,196 Coldcard-generated addresses of ~1,082.65 BTC (~$70.2M) in 41 minutes (The Hacker News) has kept expanding: Galaxy Research now tracks about $88.6 million stolen across 4,585 addresses in three waves (Decrypt; CoinDesk puts it near $89M across 4,500+ addresses), and Fortune/Yahoo report the attackers have moved roughly 1,816 BTC — nearly $116 million — off compromised wallets. Root cause: a firmware flaw dating to around March 2021 let seed generation fall back to a weak software PRNG instead of the hardware RNG. Emergency firmware shipped July 31, but patching does not repair an exposed seed — generate a new one and move funds.

Espionage

Storm-2945: fake updates over hijacked hotel Wi-Fi

Microsoft says the CaptiveCrunch operation — attributed to Storm-2945, an assessed sub-cluster of Midnight Blizzard (APT29/Cozy Bear, tied by the U.S. and U.K. to Russia's SVR) — hijacked hotel captive-portal gateways that doubled as DNS resolvers, forging DNS answers to redirect laptops' connectivity checks to fake browser updates delivering CornFlake, a RAT that captures webcam images, microphone audio and keystrokes (The Hacker News).

Supply chain

Adform ad script poisoned to swap crypto wallet addresses

Attackers modified a JavaScript file served by ad-tech firm Adform, turning it into a browser-side tool that rewrites cryptocurrency wallet addresses on customer sites. Adform detected and removed the code on July 27; anyone who copied a Bitcoin, Ethereum or Tron address on an affected page that day may have pasted an attacker's address instead — and the altered file may still sit in browser caches (The Hacker News).

NewHealthcare

DentaQuest confirmed as the year's largest healthcare breach: 15 million affected

The May 2026 ransomware attack on dental-benefits giant DentaQuest has been confirmed as the largest healthcare data breach reported this year, affecting 15 million individuals (Kaseya's Week in Breach, Aug 5) — exposed data includes SSNs and Medicaid/Medicare IDs, with the attack attributed to ShinyHunters in initial reporting (Security Boulevard, Jul 31), which had cited a higher 23M+ figure — the confirmed count now stands lower. The same weekly roundup names health-tech firm Omnicell among the latest cyberattack victims across healthcare, energy and technology.
