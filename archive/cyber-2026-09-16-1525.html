Top Story

Mandiant: an attacker hijacked a live AI coding-assistant session, then spread Shai-Hulud across about 100 repositories

Mandiant says an attacker took over an active AI coding-assistant session at an unnamed software-as-a-service provider. Before the repository spread, the assistant recommended software the attacker had poisoned — and the recommendation was accepted.

From there the attacker used the developer’s active session to install an infostealer through a poisoned PyPI package and stole GitHub OAuth tokens, then deployed the self-spreading Shai-Hulud worm across roughly 100 internal code repositories. The worm stole repository secrets and source code for the company’s products, and the attacker also poisoned a package in the company’s own supply chain.

The case appears in Mandiant’s September 2026 report. The public case study does not say when the intrusion happened or how the attacker took over the active session — both gaps are left as gaps here.

Patch Priority — ConnectWise ScreenConnect, CVE-2026-84869, 2 days overdue

CISA added CVE-2026-84869 to the Known Exploited Vulnerabilities catalog on 11 September with a remediation deadline of 14 September under BOD 26-04, and separately flagged it as requiring forensic triage — patching is explicitly not the whole response. The flaw is improper privilege management (CWE-269) plus missing authorization (CWE-862): an attacker can transfer files to a device and execute them during an active remote ScreenConnect session without the host user’s authorization or confirmation. Check whether instances were internet-exposed, review file-transfer and child-process records, and consider credential resets and session-token invalidation.

Threat Actor Spotlight

NightEagle (APT-Q-95), alongside Hacking Cat and Toy Ghouls

Kaspersky reports three activity clusters targeting enterprises in Russia with backdoors, ransomware and wipers. NightEagle — also tracked as APT-Q-95 and active since at least 2023 — is using new persistence and lateral-movement techniques. “In most incidents, the attackers used compromised valid credentials to gain access to corporate VPNs,” Kaspersky said, with connections originating from Russian-segment IP addresses linked to Cloudflare WARP tunnels and from European virtual infrastructure providers. The intrusions deploy GhostContainer, a modular backdoor that gives operators complete access to a victim’s Microsoft Exchange Server and the ability to run arbitrary code.

Issabel Framework flaw exploited for unauthenticated command execution

CVE-2026-89026 is under active exploitation. The framework ships a hard-coded HS256 JWT signing key in the pbxapi index.php file that is identical across every installation, so an unauthenticated attacker can forge valid bearer tokens, call the /pbxapi/manager/originate endpoint with the System application parameter and have Asterisk run arbitrary OS commands as the Asterisk user. A patch was pushed on 1 August 2026.

Forged admin tokens aimed at WSO2 API Manager

CVE-2026-5430, an improper verification of a cryptographic signature, is under active exploitation.   • CVE-2026-76461 — Cisco Secure Email Gateway, AsyncOS, 9.8. Due 17 Sep (1 day left).
  • CVE-2026-85706 — GitLab CE/EE path traversal, 10.0. Due 14 Sep (overdue by 2 days).
  • CVE-2026-67277 and CVE-2026-86060 — MikroTik RouterOS. Due 13 Sep (overdue by 3 days); 86060 carries an explicit forensic-triage requirement.
  • CVE-2025-25249 (Fortinet), CVE-2026-19490 (Citrix NetScaler), CVE-2026-87491 (Chromium V8) and CVE-2026-20079 (Cisco Firewall Management Center) — added 9 Sep, due 12 Sep (overdue by 4 days).
Deadlines here are the CISA-stated date per CVE. BOD 26-04, issued 10 June 2026, supersedes and revokes BOD 22-01 and replaces the old flat three-week window with a risk-based matrix in which the most dangerous tier must be remediated within three days. A same-week deadline is therefore normal and is not “corrected” here. KEV entry also requires evidence of exploitation, so a severe flaw with no confirmed exploitation carries no federal deadline at all. cisa.gov returned an empty body on direct fetch again this run; the ScreenConnect dates come from Cyber Security News reading the CISA entry.
