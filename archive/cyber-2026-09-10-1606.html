Top Story

CISA puts Cisco, Citrix and Fortinet edge flaws on a two-day federal clock

CISA on Wednesday added three vulnerabilities — one each in Cisco, Citrix and Fortinet products — to its Known Exploited Vulnerabilities catalog, requiring Federal Civilian Executive Branch agencies to apply patches by September 12, 2026. All three sit on internet-facing infrastructure.

The most severe is CVE-2026-20079 (CVSS 10.0), an authentication bypass in the web interface of Cisco Secure Firewall Management Center that lets an unauthenticated remote attacker execute script files and obtain root on the underlying operating system. Cisco updated its own advisory to say it became aware of active exploitation attempts in August 2026, without disclosing further detail.

The Citrix entry, CVE-2026-19490 (CVSS 9.3), affects NetScaler ADC and NetScaler Gateway when configured as an AAA virtual server or Gateway. Previdian's honeypots have logged 56 exploitation attempts since September 3, with 36 of them on September 8 alone. The Fortinet entry, CVE-2025-25249 (CVSS 7.3), is the heap overflow being weaponised by the PivotC2 campaign profiled below.

Patch Priority · Today

CVE-2026-20079 — Cisco Secure Firewall Management Center (CVSS 10.0). Unauthenticated auth bypass leading to root. Confirmed exploitation attempts since August 2026; CISA federal remediation deadline Friday, September 12, 2026. If you run an internet-reachable FMC web interface, patch or restrict it today, then work down to the Citrix NetScaler and Fortinet entries on the same deadline.

Threat Actor Spotlight

The PivotC2 operator — FortiGate boxes as footholds

SOCRadar attributes the campaign weaponising CVE-2025-25249 to a Russian-speaking, financially motivated actor. More than 3,000 IP addresses have been targeted, resulting in 178 infected devices, with compromises concentrated in the United States. The earliest evidence of exploitation dates to July 2026.

The payload is a Node.js remote access trojan codenamed PivotC2. A shell script carrying an exploit binary establishes a reverse shell on a vulnerable FortiGate instance and runs a one-line Node.js command, pulling a second-stage JavaScript payload that is decrypted and executed. PivotC2 then holds a persistent outbound TLS channel to its C2 and supports interactive shells, file transfer, SOCKS5/HTTP proxy tunnelling, local and remote port forwarding, CIDR-range scanning, and FortiGate-specific configuration harvesting and credential decryption. An auto-mode flag runs a predefined command sequence on first infection without an operator present.

Thomson Reuters C-Track breach may have exposed SSNs and sealed court files

An unauthorized party obtained files from C-Track, the court case-management platform sold by Thomson Reuters' West Publishing unit, affecting courts in 11 U.S. states, the U.S. Virgin Islands and Ontario. Unauthorized access ran March 1 to June 29, 2026; West Publishing discovered it on June 30. Exposed records may include names, Social Security numbers, driver's licence numbers, dates of birth, and medical and health-insurance information — including sealed records meant to shield domestic-violence victims, informants and defendants. Twelve months of Experian IdentityWorks monitoring is offered, with enrolment open until December 31, 2026.

JetBrains Cadence breached through an unpatched TeamCity server

Attackers exploited CVE-2026-63077, an insecure-deserialisation flaw in TeamCity server-to-build-agent communications, to reach the JetBrains Cadence cloud compute service between August 8 and August 24, 2026. Extracted data included usernames, real names, email addresses, last-login timestamps and last-accessed IPs, plus multiple AWS IAM credentials, project source code, configuration files and secrets held in a 2024 Cadence server backup, along with files in S3 buckets inside JetBrains AWS accounts. JetBrains found the activity on August 23 and took the server offline the next day; Cadence users are told to rotate every credential used in their executions.

NewAI infrastructureCredential harvesting

Langflow and Rails flaws turned into credential-probing infrastructure

VulnCheck reports active exploitation of CVE-2026-0768 (CVSS 9.8, unvalidated input in Langflow allowing arbitrary Python execution as root) and CVE-2026-66066, "KindaRails2Shell" (CVSS 9.5, arbitrary file read leaking secret_key_base, the Rails master key, database passwords, cloud storage credentials and API tokens). Detections went from 50-plus within hours on August 30 to 360. Attacker requests query LANGFLOW_SUPERUSER, OPENAI_API*, AWS_ACCESS* and AWS_SECRET*, read the Langflow secret key from disk, and check .ssh access. VulnCheck counted more than 7,100 exposed vulnerable Rails instances in early August.

SonicWall SMA1000 zero-days chained for unauthenticated RCE

SonicWall disclosed CVE-2026-83548 (server-side request forgery) and CVE-2026-83549 (OS command injection) in SMA1000 appliances on September 1, 2026, both exploited in the wild and chainable to achieve unauthenticated remote code execution. Both were added to CISA's KEV catalog in the September 2 batch of seven.

  • Note on the clock: 2026 KEV additions are carrying remediation windows of days, not the three-week window of the old BOD 22-01 default. The September 9 batch was listed on a Wednesday and is due that Saturday.

Also Moving

  • Microsoft's September Patch Tuesday addressed 974 CVEs by the count of The Cyber Express and Cybernews — a record — including two flaws exploited in the wild: CVE-2026-81963, an elevation of privilege in the Windows Update Stack reaching SYSTEM via improper link resolution, and CVE-2026-85880, a heap overflow enabling an out-of-bounds write to SYSTEM. Outlets differ on the headline number because they count fixes shipped earlier in the month differently.
  • More than 110 of the flaws patched carry a critical rating, and nearly 90% fall into three buckets: privilege escalation, remote code execution and information disclosure.
  • N-able issued a fourth N-central hotfix in five weeks for an unauthenticated RCE flaw; MikroTik routers are being hijacked through internet-exposed SSH without authentication; and Google shipped a Chrome update for an actively exploited V8 zero-day.
